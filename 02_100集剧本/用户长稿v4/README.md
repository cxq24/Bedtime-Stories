## 稿源与导出

- `结构化JSON/ep001.json`至`ep100.json`为该版稿源，口播只来自`narration_paragraphs[].text`。不能把标题、主题或制作说明读进去。

- `单集记录/ep004`至`ep100`保存本次稿源处理和真实媒体状态；不把稿件导入记作视频完成。
- 项目根目录执行`python3 local/export_long_scripts.py --output-dir <02_100集剧本/阅读与审校下的独立目录>`导出完整合集、单集Markdown与一致性校验；`--validate-only`为只读检查。
- 修改先写JSON、更新口播摘要与版本记录，再导出验证。段落在不同镜头或字幕中可拆分，但口播内容不可漏掉或重复。

## 制作决定

晓晓rate=-35% / pitch=-2Hz / volume=+0%，48kHz；完整读完，不设五分钟上限，不为时长删文或拉伸旧音频，不新增具体年龄说明。004正式分镜35镜已制作，005–100尚未制作；这些集JSON中shots为空不是九镜占位。先拆完整分镜草案，再依实际音频校准、锁定后逐镜配图。

通常8–10秒一幅，尽量不超过15秒，需要时3–5秒切换；图片内部静止，25fps、0.96秒叠化。短语字幕独立换条，76px汉字／48px拼音继续执行。角色身份固定、服装可按活动变化；入镜角色必须有真实可加载的参考图片。共用角色参考图已生成并迁至03_素材与参数；004长稿音频及视频已生成并获用户认可，005–100未制作。
