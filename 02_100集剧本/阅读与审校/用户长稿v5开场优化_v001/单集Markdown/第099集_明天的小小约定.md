# 第099集：明天的小小约定

主题：让期待不变成今晚的任务

小朋友们，准备好听故事了吗？今天的故事叫《明天的小小约定》。花苞还要等一等才会开放，皮皮和芽芽怎样把期待留到明天呢？

春去秋来，皮皮窗台上那盆精心照料的小植物，在这个温暖的季节里，又一次抽出了新的花枝，顶端结出了一枚饱胀的、透着一点点淡粉色的圆花苞。
今天傍晚放学回家的时候，小鹿芽芽和皮皮一起趴在窗台边看了看，芽芽惊喜地说：“皮皮，你看它的花瓣尖儿都露出来一点点了，说不定明天或者后天早上，它就要开花啦！”

到了晚上准备睡觉前，皮皮走到窗台旁，弯下腰，对着那枚安静的小花苞，用极轻极柔的声音说：“小花苞，我们拉个勾，明天早上我醒来的时候，再来看看你慢慢长成什么样，好不好？”
小花苞当然不会开口说话，也没有像小动物一样点点头；它只是在两片翠绿叶子的簇拥下，圆圆地、安安静静地合拢着自己淡绿色的小外衣，在夜色里稳稳地站着。

皮皮看了看放在花盆旁边的细嘴小水壶。傍晚的时候，他其实已经给花盆浇过适量、足够的水了，泥土现在还是湿润松软的。
皮皮忍住了想要再多浇一壶水、或者把台灯搬过来照着它，想催着它在今晚赶快长高、赶快开花的念头。因为他知道，真正的关心是顺应花苞自己的时间，而不是急匆匆地帮它加速。

皮皮转身从书架上拿来自己空白的写生小画册，平平地放到书桌的一角，旁边摆好了一支削好的粉色彩铅。
他想好了：明天早上醒来以后，如果小花苞愿意打开一两片花瓣，他就在画册上画下它刚盛开的新样子；

就算明天早上醒来，小花苞觉得还没睡够、还没有打开，那也一点儿关系都没有！他同样可以画一画清晨的露珠，至于和花朵盛开的那场小小相见，完全可以不慌不忙地慢慢来。
安置好画册后，皮皮回到小木床上，把胡萝卜玩偶抱好。你看，和明天的小小约定已经轻轻松松地留好了，那是属于明天的快乐，绝对不是今晚需要熬夜去提前完成的任务。

身下的暖黄毛毯是那么柔软，头下的大枕头是那么安稳。今天的小兔子皮皮，现在唯一需要做的事情，就是把“今天”这最后一点点时间，舒舒服服地睡过去。
皮皮闭上眼睛，他觉得自己心里关于“明天”的那些期待，就像桌角那本夹好了书签的小画册一样，也安安静静地合上了封皮。

小朋友，不管明天有什么好玩的事在等着你，都请把那份期待轻轻留在明天吧。现在，先睡一个长长的、好好陪伴自己的香甜好觉。晚安。
