# 第089集：窗上的小小剧场

主题：喜欢的游戏可以自然谢幕

小朋友们，准备好听故事了吗？今天的故事叫《窗上的小小剧场》。影子小剧场演到最后，皮皮会怎样让这场游戏自然谢幕呢？

今天下午，森林学堂里演了一场精彩的皮影木偶戏。幕布后面点着灯，纸剪的小蝴蝶和小狐狸在幕布上走来走去，把大家看得入了迷。
傍晚放学回家后，皮皮也想在自己的卧室里，演一场属于自己的小小影子戏。

吃过晚饭，皮皮用硬卡纸剪了一片带长柄的枫叶形状。他走到窗边，把浅绿色的叶子花窗帘拉平，当作小剧场的幕布；然后把剪好的纸枫叶，举到了窗边小台灯的前面。
暖黄色的灯光一照，哇，平整的窗帘布面上，立刻多出了一道边缘柔柔的、放大的枫叶影子！

皮皮压低声音，自己给自己当旁白，捏着纸柄慢慢地往右挪一挪。窗帘上的那道叶影，看起来就像是在森林的小路上散步；接着，皮皮又把纸叶子慢慢往下一落，停在窗台边缘的影子上，叶影看起来就像是走累了，稳稳地坐到了一张安静的小椅子上。
这个光影小游戏真是太好玩了！如果是平时，皮皮可能会一直换各种纸片演下去，越演越兴奋。

但今晚，皮皮看了看墙上的挂钟，知道快到睡觉的时间了。
他没有让这场好玩的表演没完没了地继续下去，而是主动给这场小小的独角戏，想了一个最温柔的结尾：只见他捏着纸枫叶缓缓往下沉，嘴里轻声念着：“太阳落山啦，小叶子回到了柔软的草地上，晚风也轻轻地停下来睡觉了。”

念完最后一句台词，皮皮干脆地把纸叶子从灯光前移开，平平地放回了书桌桌面上。
就在纸片离开灯光的那一瞬间，窗帘幕布上的那道枫叶影子，便安安静静、毫无留恋地退回到了柔软的夜色里，不见了。

房间里没有热烈的掌声，皮皮也不用再返场重演一遍。因为这座窗上的小小剧场，已经把今天傍晚的快乐和喜欢，演得完完整整、好得不能再好了。
皮皮把剪刀和纸片收进抽屉，把窗边的小木椅推稳，慢吞吞地走回了自己真正的小木床前。

床上，胡萝卜玩偶正乖乖地靠在枕头边的臂弯位置，看起来就像一个从头到尾安安静静看完了整场演出的忠实小观众，现在也打着哈欠，准备和演员一起歇一歇了。
皮皮钻进被窝，盖好暖黄色的毛毯，闭上眼睛。今晚的小小剧场轻轻落幕了，整间卧室也彻底不再忙碌了。

小朋友，白天再好玩的游戏、再精彩的动画片，到了晚上也都有落幕休息的时候。喜欢的游戏可以留到明天再继续，现在，让你的身体和眼睛都舒舒服服地休息吧。晚安。
