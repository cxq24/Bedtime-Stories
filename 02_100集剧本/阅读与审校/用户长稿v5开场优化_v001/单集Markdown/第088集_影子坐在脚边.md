# 第088集：影子坐在脚边

主题：认识熟悉的陪伴并放松

小朋友们，准备好听故事了吗？今天的故事叫《影子坐在脚边》。影子一直陪在皮皮身边，知道它是什么以后，心里会有什么变化呢？

小时候刚学走路那会儿，皮皮曾经对跟在自己身后的黑影子感到过好奇，有时候在傍晚看到拉得长长的影子，还会有一点点小小的紧张。
不过现在的皮皮已经长大了，在森林学堂的科学课上，他早就知道了影子是怎么来的——哪里有温暖的光，哪里就会有安静的影子小伙伴。

今天晚上洗完澡后，皮皮穿好睡衣，坐在自己小木床的床沿上擦干头发。
床头柜上那盏熟悉的暖黄色小台灯亮着，柔和的光线从皮皮身后斜斜地照过来，把皮皮毛茸茸的身影，轻轻地投射在了床前的木地板上；就连他头顶那两只长长的兔耳朵，也在地板上变成了两道长长的、柔和的耳朵影子。

皮皮觉得很有趣，他坐在床沿上，轻轻地往左挪了挪小脚丫；地板上的影子立刻听话地跟着往左慢慢挪了一点。皮皮又晃了晃长耳朵，地上的长耳朵影子也跟着轻轻摆了摆，就像一个从来不出声、却形影不离的安静小伙伴。
皮皮没有再故意手舞足蹈地去做很多夸张的动作，那样会让影子也在墙上和地上慌慌张张地乱晃。

他只是安安静静地把两只小脚平放在床边的软地垫上。当他的小脚停稳时，地板上的影子也立刻乖乖地缩成圆润的一团，稳稳地停在了他的脚边，像是坐在地垫上陪着他一样。
接着，皮皮伸出小爪子，把床头台灯的亮度调暗了一档。随着灯光变柔，地板上那团影子的边缘也立刻变得模模糊糊、软绵绵的，不再黑白分明，而是化作了一小块淡淡的、温柔的夜色。

你看，这位不出声的影子小伙伴，其实就来自我们身边最温暖的小台灯呀。它一点儿也不可怕，也不需要皮皮特意搬把椅子给它另外找座位，只要灯光柔下来，它就会自己安静地待着。
皮皮掀开被角，把两只小脚丫收进了暖黄色的毛毯里，抱好胡萝卜玩偶躺了下来。随着他钻进被窝，地板上那个长长的影子，也慢慢地缩回到床沿底下，藏起来休息了。

卧室还是每天住着的那间熟悉的卧室，圆圆的小木门和挂着花窗帘的窗户，都安安静静地留在原来的地方。
皮皮闭上眼睛，再也不需要抬起小脑袋去查看影子有没有跟上来，因为身下这张暖暖的小木床，已经无比稳当、无比安全。

小朋友，屋里柔和的灯光和淡淡的影子，都是夜晚最熟悉的陪伴。现在，把你的小脚丫收进被窝里安顿好吧，熟悉的夜晚会轻轻保护着你的好梦。晚安。
