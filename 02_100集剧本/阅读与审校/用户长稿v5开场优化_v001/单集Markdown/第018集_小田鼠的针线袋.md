# 第018集：小田鼠的针线袋

主题：东西各有安静的归处

小朋友们，准备好听故事了吗？今天的故事叫《小田鼠的针线袋》。毛毯边开了一道小口子，小田鼠米米会怎样帮它找回整齐的样子呢？

皮皮那条最喜欢的暖黄色小毛毯，已经陪了他好久好久了。
今天中午在学堂午睡的时候，皮皮不小心被小木床的边角勾了一下，毛毯的边边上开了一道小小的线口，露出了一点点白色的棉絮。

皮皮有点心疼，放学的时候一直把那个小破口捧在手心里。
住在隔壁橡树根下的小田鼠米米看到了，米米心灵手巧，最擅长做缝补的活儿。她主动背着自己那只鼓鼓囊囊的花布针线袋，跟皮皮一起回到了小木屋。

在傍晚柔和的灯光下，米米戴上小小顶针，穿好柔和的黄棉线，一针，一线，帮皮皮把毛毯上的小开线细心地缝合好了。
缝好之后，米米准备收拾针线袋回家。刚才为了找颜色最搭的线，针线袋口的彩色布带散开着，好几个圆圆的小木头线轴靠在桌子边上，像几只随时准备滚下山坡的小木轮。

皮皮没有袖手旁观，他坐在米米对面，轻声说：“米米，谢谢你帮我修好毛毯，现在让我来帮你送这些小工具回家吧。”
他们分工合作，一点儿也不慌乱。米米先把尖尖的缝衣针，一根根数好，稳稳地插进厚厚的绒布针包里；皮皮则伸出小爪子，把桌上的小木头线轴，按照从大到小的顺序，一个个放回针线袋里软软的布隔层中。

红色线轴住进左边的小房间，黄色线轴住进右边的小房间，谁也不会撞到谁。
接着，他们一起慢慢理好袋口散开的布带，轻轻一拉，打了一个松软又牢靠的蝴蝶结。花布袋子合上了，再也没有小东西会滚出来了。

米米开心地拎起整理好的小袋子，在门口跟皮皮轻轻道别。
皮皮回到卧室，摸了摸小毛毯的边角，新缝上的线脚平平整整、密密实实的。那个开线的小地方，并没有变成一条全新的毯子，只是因为被认真地照顾和修补过，又能暖暖和和地好好陪着他了。

皮皮把毛毯铺上小床，特意让修好的那一角，靠在自己暖暖的小脚丫旁边。
他抱起胡萝卜玩偶，慢慢闭上眼睛。尖尖的针和长长的线都回到了自己的布袋小窝里，而皮皮忙碌了一天的小爪子，也终于回到了温暖的被窝里。

小朋友，今天用过的玩具、做过的事，都已经各自找到了安静的归处。现在，让你的小手和小脚也彻底放轻松，好好歇一歇吧。晚安。
