# 第059集：屋檐下的小翅膀

主题：各自回到适合自己的休息处

小朋友们，准备好听故事了吗？今天的故事叫《屋檐下的小翅膀》。屋檐下传来小小的叫声，一只小鸟会在哪里找到自己的休息处呢？

暮春的傍晚，空气暖洋洋的。皮皮在门廊下帮妈妈把晾晒好的小竹垫收起来，再把门廊外的小木凳搬到靠墙的角落放稳。
就在他直起腰、拍拍小爪子准备回屋的时候，头顶上传来“啾”的一声轻叫，一道轻捷的黑白色身影从夕阳里掠过，稳稳地落在了小木屋门廊高高的木头屋檐下。

皮皮仰起小脑袋一看，原来是今年春天刚搬来屋檐下筑巢的那只小燕子！
白天的时候，皮皮在学堂操场上见过它，那时候它正张开剪刀似的小翅膀，一会儿掠过绿油油的草地，一会儿贴着哗啦啦的小溪水面飞翔，飞得又快又高。

而现在，太阳落山了，小燕子飞回了自己用泥巴和干草搭成的温暖小巢边。它那双细小却有力的小脚，稳稳地抓着屋檐下那根熟悉的横木梁，把白天张得大大的两只小翅膀，顺顺当当地收拢在了身体两侧。
皮皮站在门下，正想把小木门大大地拉开，把门廊外剩下的小工具箱也叮叮当当地搬进屋里。

可他看了看头顶正在整理羽毛准备睡觉的小燕子，立刻把拉门的手收住了，只把木门轻轻推开一道够自己侧身走进去的窄缝。
那个小工具箱放在有顶棚的门廊角落里也很安全，今晚不用再去叮叮当当地搬动它，免得吵到了刚落脚的小邻居。

皮皮放轻脚步溜进屋里，轻轻合上门。高高的木屋檐替小燕子挡住夜风、留着安静；而温暖的小木屋则替皮皮亮着床头灯、留着柔软的小床。不管是天上飞的小鸟，还是地上跑的小兔子，在傍晚的时候，都回到了自己最熟悉、最安心的地方。
洗漱完后，皮皮站在卧室窗内，悄悄往屋檐的方向望了最后一眼。夜色里，小燕子的翅膀尖贴得平平整整的，小脑袋缩在羽毛里，再也不准备起飞了。

皮皮微笑着把叶子花窗帘拉近了一点，给自己的小木床也留下一块柔柔的、不被打扰的夜色。
暖黄色的毛毯盖到肩头，两只长耳朵舒舒服服地靠在枕头边。忙碌了一整天的小爪子，也像小燕子收起翅膀一样，在被窝里彻底停稳了。

皮皮慢慢闭上眼睛。屋檐下的小翅膀歇着，屋里小床上的小身体，也安安静静地歇着。
小朋友，白天的奔跑和飞行都已经圆满结束啦。现在，收起你的小翅膀，回到自己温暖舒服的被窝里，慢慢睡去吧，晚安。
