# 第095集：床头留一块空地方

主题：让身边的空间安静下来

小朋友们，准备好听故事了吗？今天的故事叫《床头留一块空地方》。床头柜上摆满了喜欢的小宝贝，皮皮会怎样留出一块安静的空地方呢？

这一个星期以来，皮皮收获了好多自己特别喜欢的小宝贝。
因为每一件都舍不得离身，每天晚上睡觉前，皮皮都会把它们一样接一样地搬到自己的床头柜和枕头边上。

到了今天晚上，当皮皮洗完澡抱着胡萝卜玩偶走到床边时，他低头一看——哎呀，自己的床头简直变成了一个满满当当的小集市！
那里放着还没看完的厚绘本、昨天刚画好的水彩小画、小松鼠团团送的油松果、小鹿芽芽送的贝壳，还有一只浅浅的原木小碟子，所有东西都挤挤挨挨地靠在一起，离枕头特别近。

皮皮想把手里的胡萝卜玩偶放到枕头边老位置上，却发现根本放不下；他的小爪子要小心翼翼地绕过绘本硬邦邦的书角、避开画纸的边缘，折腾了好半天，才能勉强挤出一点点小地方。
躺下来的时候，皮皮也觉得脑袋旁边热热闹闹、满满当当的，连翻个身都怕把哪件宝贝碰掉到地上去。

皮皮重新坐起身，看着眼前这一大堆心爱的小物件想了想：虽然我都很喜欢它们，可是如果把所有喜欢的东西全都堆在脑袋旁边，连呼吸和放手的地方都没有了，那怎么能睡得踏实呢？
于是，皮皮开始动手给床头“减负”了。

他先把那本厚厚的绘本双手捧起来，走两步放回了旁边的书架上；接着，他把那张水彩小画平整地夹进书桌的画夹里；最后，他把散落的油松果和小贝壳，轻轻收进那只浅木碟里，端到了窗台内侧的角落放稳。
不过短短两分钟的工夫，原本拥挤不堪的床头柜和枕头边，一下子空了出来，留出了一大块干干净净、平平整整的原木空地方！床头灯暖黄色的光芒落下来，好像也终于有了地方可以舒舒服服地坐下了。

这回，胡萝卜玩偶宽宽敞敞地靠在了枕边，皮皮的小爪子也能随心所欲地轻轻放着，再也不用提心吊胆地去绕开每一件东西的边角了。
而且皮皮看了一眼卧室，那些他喜欢的小物件，其实哪一件都没有走远呀，它们只是各自回到了房间里更合适、更体面的位置上。

皮皮舒舒服服地躺下来，在被窝里也给自己的身体留出了一点不拥挤的宽松空间，暖黄色的毛毯松松软软地盖在身上。
他闭上眼睛。床头空出来的那块地方，一点儿也没有让房间少掉温柔，反而让今晚的安静和舒服，离自己更近了一点。

小朋友，睡前的时候，给你的枕头边和心里，也都留出一块干干净净的空地方吧。不用装满玩具和心事，轻轻靠好，在宽敞的安静里慢慢睡去吧，晚安。
