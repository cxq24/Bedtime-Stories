# 第040集：秋天的声音盒

主题：回忆可以轻轻收藏而不用重演

小朋友们，准备好听故事了吗？今天的故事叫《秋天的声音盒》。团团和芽芽最喜欢秋天的不同声音，他们会把这些声音收藏在哪里呢？

秋天快要过去的时候，山羊老师在森林学堂里问大家：“你们最喜欢秋天的什么声音呀？”
小松鼠团团说喜欢啃坚果的“咔嚓”声，小鹿芽芽说喜欢秋风吹过芦苇的“呼呼”声。

皮皮听着大家的回答，觉得秋天的每一种声音都好听极了。
傍晚放学回到家，皮皮从柜子里翻出了一只空空的、带盖子的小松木盒。他突发奇想，想把今天在森林里听过的所有好听的秋天声音，全都装进这只小木盒里收藏起来。

他捧着打开的小木盒走到门廊下，心里默念着：我要装进脚踩落叶的“沙沙”声，装进熟透的松果掉在泥土上的“噗通”声，还要装进好朋友小熊绒绒走到门前时、慢慢停住的温柔脚步声。
装了一会儿，皮皮赶紧把木盒盖子合上，抱回安静的卧室里。

他满怀期待地把小耳朵贴在木盒盖子上，打开一条小缝仔细地听——咦？木盒里空空荡荡的，什么声音也没有传出来。皮皮贴近了再听一听，只能听见卧室里安安静静的夜色，和自己轻轻的呼吸声。
原来，声音是没法像栗子一样被抓进盒子里的。

皮皮摸着下巴想了想，一点儿也没有觉得失望。他走到桌边，拿来一片今天和绒绒一起散步时捡到的红叶，轻轻地平放在了小木盒的底部。
当他看着这片红叶时，耳边好像自然而然就响起了白天踩在落叶上的“沙沙”声，还有朋友们开心的笑声。

原来，那些好听的声音，根本不需要锁在木头盒子里，它们早就变成了温暖的记忆，稳稳地住在自己的小脑袋和心里啦；只要看见这片小叶子，随时都能想起来。
皮皮笑着把小木盒盖好，端端正正地放回书架上。今晚，他不用再为了留住秋天的声音，把白天走过的每一段路重新走一遍了。

窗外的秋夜，也像合上了盖子的木盒一样，慢慢放轻了所有的声响。
皮皮钻进被窝，盖好暖黄色的毛毯，把胡萝卜玩偶抱在胸前。书架上的小木盒歇着，他的小爪子和长耳朵也歇着。

皮皮闭上眼睛，嘴角轻轻弯着。今天度过的好时光，已经永远不怕忘记了。
小朋友，把今天开心的回忆轻轻留在心里吧。现在，不去想白天的热闹，静静听一听夜晚的安静，慢慢睡吧。晚安。
