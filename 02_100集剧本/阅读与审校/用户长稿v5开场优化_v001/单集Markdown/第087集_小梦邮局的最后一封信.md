# 第087集：小梦邮局的最后一封信

主题：结束付出后也给自己一句晚安

小朋友们，准备好听故事了吗？今天的故事叫《小梦邮局的最后一封信》。皮皮做完了好梦小邮差，最后一封祝福会送给谁呢？

这个星期，森林学堂里开展了一个特别温馨的活动，叫作“好梦小邮差”。每个小朋友都可以画一些小小的祝福卡片，放进班级的信箱里，送给自己的好朋友。
皮皮被大家推选为这个星期的“小梦邮局局长”，每天负责帮大家整理和派发卡片，他干得可热心、可认真了。

今天是星期五的傍晚，皮皮回到家里，坐在卧室的书桌前，用彩色铅笔在画纸上画了一间童话般的“小梦邮局”：邮局有圆圆的木头小窗户，门口还立着一只天蓝色的小信箱。
画好邮局后，皮皮裁出几张方形的小纸片，开始给自己最要好的朋友们准备周末的“晚安好梦信”。

他先给力气大却爱害羞的小熊绒绒，画了一片软绵绵的大白云，祝他睡得像云朵一样软；接着，他给贪吃又活泼的小松鼠团团，画了一枚饱满的大松果；然后，他又给怕扎到别人的小刺猬栗栗，画了一块厚实平整的小坐垫。
每一张小纸片，都是皮皮想送给好朋友的一份专属好梦。画完之后，皮皮把这几张满载心意的小纸片，一张张整整齐齐地放进了画纸旁边的松木小盒子里，准备下周一带去学堂发给大家。

忙活了好半天，皮皮伸了个懒腰，正准备把彩铅收回笔筒里去睡觉。
就在这时，他低头一看，发现在书桌的右下角，还安安静静地躺着最后一张空着的小纸片！

皮皮拿起那张空白的小纸片愣了一下：小熊有了，小松鼠有了，小刺猬和小鹿也都有了……我给身边所有的小伙伴都送去了好梦，那这一整天忙着照顾大家的我自己呢？
皮皮微微一笑，重新拿起暖黄色的彩铅，在这最后一张小纸片上，认认真真地画了一张结实的小木床，又在木床上画了一条蓬松的暖黄色小毛毯，和一只小小的胡萝卜玩偶。

这最后一封温柔的晚安信，是皮皮专门写给自己的！
把给自己的信也放进木盒最上面后，皮皮轻轻合上了木盒的盖子，在心里宣布：“叮咚，今晚的小梦邮局正式下班关门啦！”明天和下周，还可以继续给朋友们送出温柔，但今晚的邮局局长要去休息了。

洗漱完毕，皮皮钻进了卧室里那张真正的小被窝，把胡萝卜玩偶抱近胸口。躺下的那一刻，他觉得自己已经稳稳当当地收到了刚才亲手写给自己的那封晚安信，全身上下都暖洋洋的。
皮皮的眼睛慢慢闭好，书桌上画着蓝色小信箱的画纸，也在柔和的床头灯光里安安静静地歇着。

小朋友，平时你一定也像皮皮一样，对爸爸妈妈和朋友们付出了许多爱与关心；今晚睡觉前，记得也要把最后一封晚安信送给自己哦。愿你做个最舒服的好梦，晚安。
