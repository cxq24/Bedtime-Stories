# 第038集：树枝给围巾让个座

主题：把喜欢的东西安稳收回

小朋友们，准备好听故事了吗？今天的故事叫《树枝给围巾让个座》。皮皮跑热了，浅黄色围巾怎样找到一个舒服的小位置呢？

深秋的早晨和傍晚有了一点点凉意，今天去上学的时候，皮皮第一次戴上了他那条用软毛线织成的浅黄色小围巾。
下午，小鹿芽芽和小熊绒绒来皮皮家院子里玩丢沙包。跑了几圈后，皮皮觉得身上暖烘烘的有点出汗，就随手把浅黄小围巾解下来，搭在了门廊旁边一棵矮灌木的树枝上。

那棵矮树枝像一只伸出来的小手臂，稳稳地替皮皮托了一整个下午的围巾。
到了傍晚，伙伴们都回家了，晚风吹过来，矮树枝上的围巾布角跟着风一晃一晃的。皮皮走到门廊边，伸出小爪子想把围巾收进屋里。

可是，就在皮皮往回一拉的时候，围巾边缘有一小段松散的毛线线圈，不小心挂在了细树枝分叉的小尖尖上，卡住了，没有马上松开。
如果是性子急的时候，使劲往回一扯，不仅毛线会被拉断，细树枝上刚刚长出来的过冬小芽苞也会被拽掉。

皮皮立刻停住了往回拉的爪子。他凑近细树枝，先不往后拽，而是顺着树枝的方向，把围巾轻轻往前送回了一点点。
这一送，原本绷得紧紧的那小段毛线线圈，立刻变得松松软软的了。

接着，皮皮用两根手指捏住线圈，顺着细枝的尖尖慢慢往上一抬、一挪——小围巾就毫发无损地回到了皮皮的怀里！而那根矮树枝轻轻晃了晃，上面圆圆的小芽苞还完好无损地留着呢。
皮皮对着矮树枝笑了笑，小声说：“谢谢你今天帮我拿围巾，现在把座位还给你啦。”

他捧着围巾走进屋，把它平平整整地叠好，放到门内专门挂衣服的小木架子上，不用让它在微凉的夜风里一直摇晃了。
门廊外的矮树枝空了出来，重新安静地待在夜色里。今天向大自然借用过的地方，已经温柔地归还好了。

洗完澡，皮皮钻进温暖的被窝。在盖被子的时候，他也特意把暖黄毛毯的四个边角都理得松松的，没有让哪一小块被子绷得紧紧的。
他把胡萝卜玩偶抱在臂弯里，慢慢闭上眼睛。不管是外面的小树枝，还是屋里的软围巾，都在今晚找到了最舒服的归处。

小朋友，如果今天你的心里也有哪件事像挂住的围巾一样拉得紧紧的，现在，往回松一松吧。暖暖地躺好，晚安。
