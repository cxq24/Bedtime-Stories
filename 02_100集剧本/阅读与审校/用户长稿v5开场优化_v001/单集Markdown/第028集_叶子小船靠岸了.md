# 第028集：叶子小船靠岸了

主题：完成后允许停留

小朋友们，准备好听故事了吗？今天的故事叫《叶子小船靠岸了》。叶子小船已经完成了旅程，它会在哪里轻轻靠岸呢？

今天在森林学堂的科学角，山羊老师带着大家做了一个关于“浮力”的小游戏，看谁能用树叶做出一艘不会沉的小船。
皮皮挑选了一片边缘微微向上卷起的厚樟树叶，它看起来就像一艘天生的小独木舟。

傍晚放学回家时，皮皮把这片心爱的“叶子小船”带回了家。
他在门廊的矮桌上，摆了一只装满清水的浅口大陶盘，小心翼翼地把卷边的樟树叶放在水面上，还在叶子船舱的正中间，放了一粒轻飘飘的粉红色小花瓣，当作坐船的小乘客。

皮皮对着水面轻轻吹了一口气，“呼——”
叶子小船便载着粉红花瓣，在水面上慢悠悠地转了半圈，优雅地航行起来。水面上倒映着屋里透出来的暖黄色窗灯，小船就像在洒满金子的湖面上旅行一样。

如果是白天的比赛，大家一定会不停地吹气，让小船一圈接一圈地快速跑下去。
可是现在天色暗了，皮皮把小爪子停在陶盘外面，没有再去拨动水面，也没有再吹气。他只是安安静静地蹲在桌边，想看看在没有风催促的时候，这艘小船自己会停在哪里。

水波慢慢平息下来。一小会儿后，那片樟树叶顺着最柔和的水流，轻轻地靠住了陶盘温润的边缘，停稳了。
船舱里的那粒粉红花瓣，还好好地坐在原处，一点儿也没有被打湿，更没有掉下来。

皮皮从花盆旁找来一块小小的扁平鹅卵石，轻轻摆在陶盘外面的桌沿上，刚好对着叶子停靠的地方，就像是给这个小小的停靠港湾，立了一个温柔的码头记号。
今天的航行圆满结束了。叶子小船不必在夜里一直漂流，花瓣小乘客也可以在这个小港湾里安心地歇一歇了。

皮皮站起身，走进卧室回到床上，把自己的两只长耳朵舒舒服服地放好。这只软绵绵的大枕头，就是皮皮今晚停靠的岸边呀。
他盖好暖黄色的毛毯，慢慢闭上眼睛。门廊水盘里的小船停稳了，屋里小床上的小兔子，也稳稳当当地停靠好了。

小朋友，白天不管是学习还是玩耍，你的小船都已经勇敢地航行了一整天。今晚，就让我们一起靠岸吧。小床会稳稳地接住你，愿你做一个安静的好梦，晚安。
