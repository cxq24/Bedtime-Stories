# 第073集：想念放在小枕头旁

主题：让想念有一个温柔的落点

小朋友们，准备好听故事了吗？今天的故事叫《想念放在小枕头旁》。朋友回家以后，皮皮把想念放在哪里，才能安心入睡呢？

今天下午，小松鼠团团来皮皮家玩了一整个下午。
他们没有玩激烈的追逐游戏，而是并排坐在门廊的木台阶上，一边分吃着香甜的烤红薯，一边仰着头，安安静静地看天上一朵走得特别慢的大白云，从屋顶的左边一直飘到屋顶的右边。

后来，团团的妈妈来接他去外婆家住两天，这意味着明天和后天，他们在学堂里暂时见不到面了。
团团临走前，从自己的小口袋里掏出了一枚他最喜欢的、圆滚滚的小油松果，塞进皮皮手里说：“皮皮，这枚松果替我陪着你，过两天我就回来啦！”

到了晚上准备睡觉的时候，小木屋里静悄悄的。皮皮坐在床沿上，心里忽然涌起了一点点对好朋友团团的想念。
他把团团留下的那枚小松果拿在手里，用指腹轻轻摸着上面层层叠叠、光滑的小鳞片，脑海里全是白天两人并肩看云的画面。

皮皮有点坐不住了，他想穿鞋走到大门口，再去院门外望一望通往团团家的那条小路。
可是他转头看了看卧室的窗户，窗外早就黑透了，银白色的月光安安静静地洒在树梢上，森林里没有一个人影。就算现在跑到门口去张望，也看不到已经去了外婆家的团团呀。

皮皮摸了摸手里的小松果，心想：想念好朋友是一份很温暖的心情，可如果整晚都把松果紧紧攥在手心里、或者站在门口吹冷风，那我的手心和身体都会累坏的。
于是，皮皮从书架上找来了一只浅浅的小木碟，铺上一层软布，把那枚小油松果端端正正地放在碟子里，再把木碟摆在了自己大枕头的正旁边。

一放下来皮皮就发现：原来想念是不用一直死死捧在手心里的；把它轻轻放在枕头边，一侧头就能看见，它离自己的心也一样很近很近。
皮皮对着枕边的小松果，用只有自己能听见的声音轻轻说了一句：“明天见，还有后天见，团团。”那句轻柔的话没有走出房间，却像一团小火苗，让皮皮的心窝一下子暖和了起来。

暖黄色的毛毯拉好了，胡萝卜玩偶抱好了。白天和朋友一起坐过的那份安静与美好，也稳稳地回到了心里。
皮皮没有再起身去门口张望。他知道，此时此刻，团团一定也在外婆家的软床上准备睡觉呢；朋友在远方好好休息，自己在这里也好好歇一歇，这就是最好的陪伴。

皮皮的眼睛慢慢合上，枕边木碟里的小松果，像一枚温柔的小记号，静静地留在床头灯的暖光里。
小朋友，如果你在睡前也有想念的人或小伙伴，把这份想念轻轻放在枕头边吧。把自己照顾好、睡个好觉，也是送给对方的一份温柔。晚安。
