# 第029集：雾抱了抱小篱笆

主题：熟悉的事物在朦胧中仍在

小朋友们，准备好听故事了吗？今天的故事叫《雾抱了抱小篱笆》。夜雾轻轻围住小篱笆，熟悉的森林还在原来的地方吗？

深秋的傍晚，森林里下过一阵小雨后，空气变得湿润又微凉。
皮皮刚帮妈妈把门廊下的小花盆收好，一抬头，发现窗外的森林里，不知什么时候升起了一层白茫茫、薄薄的夜雾。

那层薄雾慢悠悠地飘过来，把皮皮家院子外面的小木头篱笆轻轻围住了，远远看去，小篱笆就像披上了一条浅灰色的蓬松羊毛围巾。
皮皮回到屋里，趴在卧室的窗台上往外看。平时站在窗前，他能一直望见远处的小木桥和小松鼠团团家的大橡树；可是今天，近处窗台边的绿叶子还清清楚楚的，远处的小路和小桥，却全都藏进了乳白色的雾气里，只剩下柔柔的、模糊的轮廓。

皮皮心里冒出了一点点小小的担心：外面的路看不清了，小篱笆和远处的森林，会不会在雾里迷路不见了呀？
他刚想走到门口去打开门看个究竟，却停住了脚步。他看了看窗台内侧，自己刚放好的那盆小绿植还稳稳地待在熟悉的角落里，床边的小木椅也还坐在原来的位置上。

皮皮明白了：花盆在这里，小椅子在这里，院子外面的小篱笆和小木桥当然也还在原来的地方呀，它们哪里也没去，只是在夜晚暂时躲进了软绵绵的雾气被子里休息呢。
于是，皮皮没有再打开门出去找。他伸出小爪子，把叶子花窗帘往中间拉近了一点，让小木屋里暖融融的灯光，严严实实地留在自己和胡萝卜玩偶的身边。

窗外的薄雾像一个温柔的大拥抱，轻轻抱了抱小篱笆，没有敲门，也没有催促屋里的谁跟着它一起往看不清的远处走。
皮皮安心地钻进被窝，把小爪子彻底放松下来。今晚那些在雾里看不清楚的远方，等明天早上太阳升起来、雾气散去的时候，随时都可以再看个够。

他靠住柔软的枕头，慢慢闭上眼睛。小木屋里熟悉的原木香气和毛毯的暖意，离他这么近，这么真实。
小朋友，到了晚上，看不清外面的大世界也没关系，因为所有美好的事物都还好好地待在原处。现在，先安心待在你熟悉的被窝里吧，有些风景留给明天的阳光。晚安。
