# 第010集：晚安小书签

主题：故事可以安心留待明天

小朋友们，准备好听故事了吗？今天的故事叫《晚安小书签》。皮皮在图书大篷车里挑了一本故事书，读不完的故事能安心留到明天吗？

每个星期五的下午，猫头鹰阿姨都会推着她的“叮当图书大篷车”来到森林学堂门口。
车上装满了厚厚的立体书、会发出香味的花朵画册，还有长长的森林冒险故事。

今天，皮皮从大篷车上借到了一本他期待了好久的绘本，名字叫《月光下的秘密花园》。
一回到家，吃过晚饭，皮皮就迫不及待地坐在床头的小灯下翻开了它。

绘本里的图画真美呀！第一页是一道爬满牵牛花的木栅栏，第二页是一条铺着彩色鹅卵石的小溪。皮皮伸出小爪子，顺着鹅卵石小路一页一页往下翻。
翻到正好一半的时候，画上出现了一扇半掩着的藤蔓小门，门后面就是那座从来没人去过的秘密花园。

皮皮好想翻开下一页看看里面有什么呀，可是这时，他打了一个长长的哈欠，眼皮有点发沉了。抬头一看，窗外已经升起了弯弯的月亮，到了该睡觉的时间。
皮皮摸了摸那页厚厚的画纸，心里有点舍不得马上合上，他怕今天不看完，明天就找不到这扇藤蔓小门了。

就在这时，皮皮想起了猫头鹰阿姨借书给他时，随书送给他的一条柔软的棉布书签。
书签是浅绿色的，一端还用绒线绣着一片小小的叶子。

皮皮拿起布书签，轻轻地把它夹在画着藤蔓小门的那一页，让那片绣花小叶子，刚好停在花园的门口。
这样一来，小叶子就会替他守着这扇门。秘密花园不用赶在今晚急匆匆地逛完，鹅卵石小路也不会在夜里走丢，明天一早翻开书，就能稳稳地找到这里。

皮皮放心地合上绘本，把它轻轻平放在床头柜上。绿色的布书签从书页间露出一小截，像在安静地对他招手说“明天见”。
皮皮把床头灯调暗，拉好暖黄色的毛毯。书里的秘密花园留在了书里，而他自己温暖的小床，就在身边。

窗外的月光溜进来，轻轻碰了碰绘本的封面，没有再翻开下一页。胡萝卜玩偶也乖乖地靠住了小枕头。
皮皮闭上眼睛，心里还留着那条通往花园的小路，不过它已经不着急往前走了。

小朋友，今天还没玩够的游戏、还没听完的故事，都可以交给明天继续。现在，夹好你心里的晚安小书签，先把自己轻轻安顿好。晚安。
