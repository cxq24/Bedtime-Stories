# 第066集：彩带的慢慢结

主题：用从容替代用力

小朋友们，准备好听故事了吗？今天的故事叫《彩带的慢慢结》。画纸已经装进盒子，皮皮要怎样从容地系好最后一根彩带呢？

这个学期，皮皮在学堂里画了好多幅漂亮的风景画。为了把这些画纸好好保存起来，今天傍晚，皮皮找来了一只扁平的长方形硬纸盒，把画纸按顺序一张张放平装好。
为了让画盒看起来更像一份珍贵的礼物，皮皮还从手工篮里找出了一条长长的、天蓝色的丝绸小彩带，想在画盒外面系一个漂亮的结。

因为丝绸彩带平时是卷在圆筒上收纳的，当皮皮把它抽出来铺在桌上时，彩带的一端就像有记忆一样，顺着原来的弧度自己慢慢地卷成了一个小圈儿。
皮皮两只小爪子捏着彩带两端，想把它一下子拉直，于是稍微使了点劲儿往两边一扯——谁知道，那个原本松散的小卷儿，被他猛地一拉，反而绕在了一起，变成了一个紧紧的小死结！

皮皮愣了一下，又试着拽了拽，越是用力气拉，丝绸彩带滑溜溜的结就缩得越紧，连带着皮皮的小鼻尖都快要急出汗来了。
皮皮赶紧停下了使劲拉扯的小爪子。他深吸了一口气，松开手，把那条天蓝色的彩带重新放回了平平整整的书桌桌面上。

没有了双手的拉拽，软软的丝绸彩带在桌面上自己松了一点儿劲。
皮皮凑近桌面，不再跟它拔河，而是伸出两根小手指，顺着彩带原本弯曲的方向，耐心地往回推了一点，慢慢展开一圈，再慢慢展开一圈……不到一会儿工夫，那个乱糟糟的小结就自己散开了，天蓝色的彩带重新变得平顺又舒展。

皮皮笑了。他把彩带轻轻绕过装满画纸的盒子，在盒盖正中间系结的时候，他没有再使大劲去勒紧，而是只打了一个松松软软的活结，让彩带的两端自然地垂落在盒边，一点儿也不强求它非得像画册里的蝴蝶结那样对称挺括。
画纸已经安安稳稳地收在盒子里了，而那个松松的、不太一样的小结，也稳稳地坐在自己合适的地方，看上去温柔极了。

皮皮把系好彩带的画盒放上书架，桌面重新空了出来，刚才因为用力而有些紧绷的小爪子，也彻底放松了。
洗漱完钻进暖黄色的毛毯里，皮皮慢慢地放平自己的小肩膀。他发现，原来对待柔软的小东西也好，对待睡前的自己也好，都不需要一直用力气去紧绷着照看。

胡萝卜玩偶轻轻靠着他的胸口，皮皮闭上眼睛，觉得心里好像也解开了一个小小的卷，变得无比顺畅。
小朋友，遇到解不开的小麻烦时，给自己一点点从容吧。把手松一点，把动作慢一点，今晚你可以舒舒服服地好好休息啦。晚安。
