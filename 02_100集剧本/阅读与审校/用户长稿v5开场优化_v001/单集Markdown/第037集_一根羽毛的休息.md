# 第037集：一根羽毛的休息

主题：轻轻的东西也可以安稳停下

小朋友们，准备好听故事了吗？今天的故事叫《一根羽毛的休息》。一根轻轻的羽毛落下来，能不能找到安稳休息的地方呢？

今天下午在森林学堂的操场上，山羊老师带着大家玩“羽毛球拍托气球”的游戏。
大家在草地上跑来跑去，仰着头，竖着耳朵，眼睛一刻也不眨地盯着空中飘浮的气球，生怕它掉在地上。皮皮玩得特别投入，连两只长耳朵都一直高高地竖着。

傍晚放学回到家，皮皮推开卧室的窗户透气时，一阵秋风吹过，一根洁白干净的小鸟羽毛，从树冠间飘飘悠悠地落了下来，正好停在了皮皮家的木头窗台上。
那根小羽毛实在是太轻、太软了。窗外只要有一丁点儿微风经过，羽毛尖上细细的绒毛就会轻轻发抖，整根羽毛也在光滑的窗台木板上转来转去，好像还带着白天的风，怎么也停不稳当。

皮皮把小爪子停在窗台旁边，没有冒失地去抓它，只是静静地看它转了半个方向，又慢吞吞地靠回窗框边。
皮皮心想：这根小羽毛在天上飞了那么久，现在一定也很想找个不会被风吹跑的地方，安安稳稳地睡一觉吧。

于是，皮皮转身从书架上找来了一只浅浅的圆形小木碟，在碟子底部铺上了一小片有些粗糙纹理的纯棉布，然后屏住呼吸，捏起羽毛根部，把它轻轻地放进了木碟里。
有了棉布温柔的摩擦力，小羽毛一下子就有了平稳的依靠，再也不会在光滑的窗台上乱滑、乱撞窗框了。它边缘那些细细密密的白色绒毛，也终于放心地舒展开来。

皮皮把这只盛着羽毛的小木碟，挪到了窗台内侧一个不挡风的安静角落里。这样，外面的窗帘依然有地方轻轻摇晃，而小羽毛也有了安稳停歇的小窝。
天色渐渐暗透了，小木碟里的白羽毛映着一小块银色的月光，一动不动，像是终于把白天所有的风都慢慢放下了。

皮皮洗漱完躺回枕头上。他摸了摸自己竖了一整天的两只长耳朵，也让它们像那根小羽毛一样，轻轻地、软软地落在了枕头两边，不用再一直竖着去听外面的动静了。
他抱住胡萝卜玩偶，闭上眼睛。窗台上的小羽毛，和小床上的小兔子，都已经安顿好了。

小朋友，把你身体里还绷着的小肩膀、小拳头，也像小羽毛一样慢慢松开吧。让轻轻的夜晚，陪你安稳休息。晚安。
