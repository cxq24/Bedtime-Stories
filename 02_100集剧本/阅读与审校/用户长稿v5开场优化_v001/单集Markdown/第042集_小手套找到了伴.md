# 第042集：小手套找到了伴

主题：不着急地整理小遗漏

小朋友们，准备好听故事了吗？今天的故事叫《小手套找到了伴》。少了一只手套也不用着急，另一只会在哪里找到新伙伴呢？

冬天的早晨和傍晚冷飕飕的，皮皮出门上学时，总会戴上妈妈给他织的那双毛茸茸的红白条纹小手套。
今天下午放学的时候，皮皮在院门口和小熊绒绒一起堆了一个小小的雪球。因为觉得戴着手套拍雪球不够灵活，皮皮进屋前，就在玄关那儿把手套摘了下来。

到了晚上准备睡觉前，皮皮像往常一样去检查明天上学要穿戴的衣物。
他把叠好的小围巾放进门边的藤编收纳篮里，可低头一看，咦？大大的篮子里，怎么只孤零零地坐着一只左手的小手套呢？右手的那只小手套去哪儿了呀？

要是放在以前，皮皮发现少了一只手套，肯定会急得在屋里团团转，甚至想拿手电筒开门跑到雪地里去找。
但是现在的皮皮遇到小麻烦时，已经学会先让自己冷静下来了。他站在玄关的暖灯下，深吸了一口气，没有马上开门跑出去，而是先在脑海里像放电影一样，回忆了一下傍晚进门时的动作。

“我进门的时候，先坐在矮木凳上换了拖鞋……”皮皮一边小声嘟囔，一边低下头，先往门边那张换鞋的矮木凳下面看去。
哈哈，找到了！原来右手的那只小手套，当时从膝盖上滑了下来，正安安静静地靠在里面的木凳脚旁边，就像跟皮皮玩捉迷藏，躲进了一个很小很小的阴影角落里。

皮皮弯下腰，高高兴兴地把那只小手套捡了起来。他用小爪子轻轻掸掉手套表面沾着的一点点细灰，然后把它放进藤编篮里，让两只红白条纹的小手套平平展展地躺在一起。
一只大拇指朝左，一只大拇指朝右，掌心挨着掌心，就像失散了一小会儿的好兄弟终于团聚了。篮子里一下子变得整整齐齐、成双成对。

皮皮把收纳篮往架子里面推稳。这样一来，明天早上出门上学的时候，就不用慌慌张张地到处找手套了，今天的小寻找已经圆满结束啦。
他迈着轻松的步子回到卧室的小床上，把自己的两只小爪子，也像那双手套一样，成双成对地放进了暖暖和和的被窝里。

胡萝卜玩偶靠着胸口，皮皮轻轻闭上眼睛。屋里所有小小的伙伴，都找到自己的伴儿，安顿好了。
小朋友，白天要是有小小的一点遗漏，只要不着急、慢慢找，总能整理好的。现在，把你的两只小手也放进温暖的被窝里，舒服地休息吧。晚安。
