# 第053集：花苞不着急

主题：尊重自己的节奏

小朋友们，准备好听故事了吗？今天的故事叫《花苞不着急》。别的花都开了，小雏菊的花苞还没打开，它可以按自己的节奏来吗？

春天越来越暖和，森林学堂的植物园里百花齐放。小松鼠团团种的迎春花已经开出了金黄色的小喇叭，小鹿芽芽种的风信子也冒出了紫色的花串。
而在皮皮家卧室的窗台上，他精心照料的那盆小雏菊，在长出了好几片锯齿状的绿叶子之后，也在茎干顶端结出了一枚圆圆的小花苞。

这几天，皮皮每次路过窗边，都会停下来看一看。
今天下午，芽芽和团团来皮皮家玩，大家围着窗台看了一圈，团团挠挠头说：“皮皮，你的小花苞怎么还紧紧地合着呀，什么时候才能开花呢？”

送走朋友们后，傍晚的阳光斜斜地照进屋里。皮皮再去窗边看时，那枚小花苞还是圆鼓鼓、绿莹莹地合拢着，像一个握紧的小拳头，安安静静地缩成小小的一团，一点儿也没有要在今天绽放的意思。
皮皮拿来画纸和五颜六色的水彩笔坐在桌前，他原本想先在纸上画一朵已经完全盛开的、有着几十片白色花瓣的大雏菊，好像这样就能催着小花苞快点打开似的。

可是，皮皮画了一笔，又抬头看看窗台上那枚安静的小花苞，手里的画笔慢慢地停了下来。
他心想：团团的迎春花开得早，是因为迎春花喜欢早春的风；而我的小雏菊还在攒力气呢，如果它现在就喜欢当一个圆圆的小花苞，我为什么要催它非得变成大花朵呢？

于是，皮皮换了一张干净的画纸，不再去画想象中的大花朵，而是老老实实地画下了小雏菊眼前的模样：
一根细细的、挺拔的绿茎，几片舒展的叶子，最顶端托着一个圆滚滚、紧紧合拢的小青苞。画完一看，哇，哪怕还没有开花，这幅画也充满了一种安静等待的力量，已经是一幅特别完整、特别好看的小画了！

这时，一阵傍晚的微风吹到窗边，叶子花窗帘轻轻飘起来。皮皮赶紧走过去，用窗帘扣把窗帘收好了一点，不让晃动的帘角碰到那根细细的花茎。
小花苞稳稳地站在窗台上，它再也不用为了迎合画纸上的大花，而慌慌张张地把自己全部打开了。

皮皮把这幅画着花苞的小画放到床头柜上。等将来哪一天花苞真正准备好了、自己绽放的时候，随时都可以再画一幅新的。
现在，皮皮先爬上床，盖好暖黄色的毛毯，把胡萝卜玩偶放到臂弯里，紧绷的小肩膀也慢慢放松下来。

皮皮闭上眼睛。窗边的花苞在安静地歇着、攒着劲儿，而小兔子也不需要在今晚就急着做完所有的事。
小朋友，每个人都有自己开花和成长的时间，按照你自己的速度慢慢来吧。今天的你，这样就已经很好了。暖暖地睡，晚安。
