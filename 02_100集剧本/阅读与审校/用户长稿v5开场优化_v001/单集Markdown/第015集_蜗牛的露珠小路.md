# 第015集：蜗牛的露珠小路

主题：慢慢走也能到达

小朋友们，准备好听故事了吗？今天的故事叫《蜗牛的露珠小路》。一颗露珠要沿着小路慢慢走，蜗牛会陪它走到哪里呢？

皮皮在森林学堂里领到了一个新任务——照顾班级自然角里的一盆大叶万年青。
这个周末，皮皮把这盆万年青抱回了自己的小木屋门廊上照看。

傍晚时分，太阳落到了远山后面，皮皮提着他的小喷水壶，来到门廊给花盆添水。
细细的水雾落在宽宽的绿叶子上，凝结成了几颗圆滚滚的小水珠。就在皮皮放下水壶的时候，他惊喜地发现，有一只背着浅棕色螺旋壳的小蜗牛，正停在最下面那片宽叶子的边缘。

小蜗牛大概也是刚放学回家吧。叶面上有几颗晶莹的小露珠，小蜗牛慢慢地伸出两根小小的触角，左探探，右探探，像是在认真地看，走哪一边才不会滑倒。
皮皮是个很有耐心的孩子，他没有好奇地用手指去推小蜗牛的壳，也没有催它快点爬。

皮皮安安静静地蹲在花盆旁边，屏住呼吸，不去打扰它。
他仔细观察，发现前面有一截卷起来的叶尖挡住了小蜗牛的去路，像一道陡峭的小坎。皮皮便伸出小爪子，极轻极轻地把那截卷起的叶尖往下扶了扶，让它变成了一条平缓的绿色小斜坡。

小蜗牛用触角碰了碰平缓的叶面，放心地往前挪了一点，再挪了一点。它背上的圆房子也稳稳当当地跟着晃动。
叶片上的一颗小露珠，映着皮皮屋里透出来的暖黄色窗灯，在小蜗牛身后闪出很淡很淡的暖光，就像一盏为它照明的小路灯。

没有谁催它快一些，晚风也吹得很慢。
过了一会儿，小蜗牛终于顺着露珠小路，爬到了宽叶子的背面，找到了一个既挡风又湿润的阴凉角落，安安静静地把触角收了回去，准备睡觉了。

皮皮看小蜗牛安顿好了，这才轻轻站起身，把花盆往屋檐下放稳。当他推开门走回小屋时，他发现自己的脚步，也不由自主地比平时慢了一点、稳了一点。
洗漱完爬上小床，皮皮的长耳朵舒舒服服地躺好了。他抱好胡萝卜玩偶，脑海里不再想着明天还要赶去哪里。

小朋友，你看，小蜗牛走得那么慢，也稳稳地到家了。今晚我们也不必赶路，因为你已经到达自己温暖的小床啦。慢慢呼吸，安心休息，晚安。
