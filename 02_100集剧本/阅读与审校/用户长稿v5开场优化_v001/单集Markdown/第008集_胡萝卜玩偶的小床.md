# 第008集：胡萝卜玩偶的小床

主题：照顾别人时也照顾自己

小朋友们，准备好听故事了吗？今天的故事叫《胡萝卜玩偶的小床》。皮皮会怎样照顾玩偶，也照顾好自己呢？

今天是学堂的“玩具宝贝日”，每个小朋友都可以带一个自己最心爱的玩偶去学校，学会怎么当一个会照顾人的小主人。
皮皮把他的胡萝卜玩偶装进小书包，小心地露出一截绿色的叶子头，一路护送到了树洞教室。

教室里可真热闹呀！小刺猬栗栗带了一只布缝的小苹果，小鼹鼠点点带了一只毛绒小铲子。
到了中午玩“过家家”的时候，皮皮特别认真地照顾胡萝卜玩偶。他把自己的小围兜解下来给玩偶当披风，又把自己坐的小垫子让了一大半给玩偶躺着，自己只用半个小屁股悬在木头凳子边上。

山羊老师走过来，看见皮皮坐得歪歪扭扭的，便温柔地笑了：“皮皮，你把胡萝卜照顾得真好，可是你自己坐得舒服吗？”
皮皮摸了摸有点发酸的小腿，摇了摇头。

山羊老师拿来一块软布，铺在皮皮怀里：“你看，让玩偶靠在你怀里，你坐满整个软垫，这样你们两个都能舒舒服服的呀。照顾好朋友的时候，也要先照顾好自己呢。”
皮皮试了试，哇，果然又稳当又暖和！

放学回到家，到了晚上睡觉的时间，皮皮还记着白天照顾玩偶的快乐。
他给胡萝卜玩偶找来一块干净的小方巾，想在自己的大枕头旁边，替它单独铺一张神气的小床。

皮皮把方巾折得方方正正，用小爪子轻轻压平两个角，让玩偶躺上去。玩偶的绿叶子朝着窗户，圆圆的身体刚好靠住枕边。
皮皮看了又看，觉得玩偶可能还会冷，就把自己的暖黄毛毯扯过去一大半，给它盖得严严实实。

这下玩偶有了豪华小床，可皮皮躺下来时却发现，自己的半边被子溜走了，晚风从脖子后面钻进来，有点凉飕飕的。
皮皮想起了白天山羊老师说的话。他没有再去柜子里找新毯子，而是把胡萝卜玩偶轻轻挪近了一点，放进自己的臂弯里，让暖暖的大毛毯，同时盖住他们两个。

那块小方巾变成了玩偶的专属小枕头。胡萝卜贴着皮皮温热的爪心，谁也不用躺得远远的，两个人都暖烘烘的。
皮皮安稳地靠好，嘴角轻轻弯着。忙着照顾玩偶了一整天的小爪子，终于也可以休息了。

小朋友，今晚睡觉的时候，给自己也留一份满满的舒服吧。
你和身边喜欢的小伙伴，都可以窝在暖暖的被子里，好好歇着。晚安。
