# 第083集：星星的慢火车

主题：把期待留在安静的画面里

小朋友们，准备好听故事了吗？今天的故事叫《星星的慢火车》。绘本里的慢火车开向星星，皮皮会把期待留在怎样的画面里呢？

今天在森林学堂的图书角，皮皮借回了一本画风特别宁静的深夜绘本，名字叫《开往银河的慢火车》。
吃过晚饭，洗完暖水澡，皮皮早早地钻进被窝，靠在床头灯柔和的光晕里，翻开了这本漂亮的图画书。

只见跨页的大图画上，画着一列小小的、亮着微光的“星星火车”，正稳稳地停靠在画纸右下方一座深蓝色的小木头车站旁。
这列火车的车厢真特别呀，它们不像平时运货的铁皮车厢那样笨重，而是一节节浅浅的、像木头小盒子一样的敞篷车厢。车厢里没有装满吵吵闹闹的乘客，也没有叮叮当当的货物，只安静地装着几团软绵绵的云影，和一汪浅金色的月光。

皮皮没有急着往后翻页，他用温和的目光，沿着画纸上那条弯弯曲曲的银色铁轨，从左往右慢慢地看过去。
那条画在夜空里的铁轨，弯得那么柔和、那么平缓，看起来简直跟皮皮腿上盖着的那条暖黄色小毛毯的布褶子一模一样！

顺着铁轨一直看到右下角的蓝色小站，皮皮发现，这列星星火车到达小站之后，就已经把车头灯调暗，不再继续往前开了。车厢侧面那几扇圆圆的小窗户里，只安安静静地亮着一点点像萤火虫一样微弱的暖色。
皮皮看着画里的火车，心里轻轻地想：原来就连天上的星星火车，跑了一天之后，也找到了今晚最适合停靠的小站；它不用在黑夜里不知疲倦地一直开到很远很远的星星上去，它也要在小站里睡一觉呢。

想到这里，皮皮觉得自己的眼皮也像到站的小火车一样，变得沉甸甸的了。
他拿起床头的布书签夹进书页里，轻轻地合上了这本厚厚的绘本。星星的慢火车稳稳地留在了图画书的蓝色小站里，而皮皮自己温暖的小木床，就在身下。

暖黄色的毛毯已经盖好了，胡萝卜玩偶也抱好了。皮皮竖起长耳朵听了听，屋里没有轰隆隆的车轮声，也没有催促出发的汽笛声，反而听见了最熟悉、最让人安心的夜晚静谧。
皮皮的眼睛慢慢闭合。他觉得自己心里白天转个不停的小车轮，也在这一刻一圈、一圈地放慢下来，最终轻轻地停住了。

小朋友，今天白天的旅程，开到这里就已经圆满到站啦。现在，把所有的期待都留在安静的图画里，让温暖的小床稳稳地接住你吧。晚安。
