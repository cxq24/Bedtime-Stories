# 第047集：雪地脚印回到家

主题：用熟悉的归途安顿心绪

小朋友们，准备好听故事了吗？今天的故事叫《雪地脚印回到家》。雪地上的脚印一行行向前，皮皮怎样沿着熟悉的路回到家呢？

今天下午，森林学堂放学前下了一场薄薄的雪，给整座森林铺上了一层洁白的糖霜。
皮皮背着小书包，和顺路的小刺猬栗栗、小松鼠团团在岔路口道别后，独自一人踩着软绵绵的薄雪，走上了通往自己家小木屋的院子小路。

走着走着，皮皮推开小木门走进门廊，回头往院子里看了一眼。
只见门前那片洁白平整的薄雪地上，留着一串他刚刚踩出来的、圆圆深深的小脚印！

皮皮觉得很有趣，趴在门框边仔细端详起自己的脚印来：
你看，刚进院门的那几个脚印，稍微靠左了一点，那是因为他刚才低头去闻了闻路边的腊梅花；中间的那几个脚印，又稍微靠右拐了个小弯，那是因为他特意绕开了门前的小花盆；到了最后，这串弯弯曲曲的小脚印，不多不少，正好稳稳地停在了小木屋的门槛前面。

皮皮坐在门内的换鞋凳上，轻轻拍掉雪地靴边缘沾着的白雪。
他看着外面那串并不算笔直的脚印想：要不要现在再跑出去，在旁边重新走一排笔直笔直、整整齐齐的脚印呢？

皮皮摇了摇头，笑了。何必呢？脚印靠左一点、靠右一点、弯一点，都一点儿也没关系呀，因为它们已经带着自己，平平安安地回到温暖的家了。
屋里的窗灯透出去，把门槛前最后那两个小脚印的边缘照得亮晶晶的。天空中又飘下了几朵零星的夜雪，正一点一点地落进脚印里，把它们的轮廓盖得更加柔软。

皮皮把雪地靴放好，光溜溜的小脚丫钻进了暖和的软袜子里。门外那条雪地小路，就彻底留给安静的冬夜了。
他坐上小床，把暖黄色的毛毯盖过脚尖。今天走过的路，没有哪一步需要重头再走一次了。

胡萝卜玩偶已经在枕边躺好了。皮皮闭上眼睛，深深吸了一口气。小脚印留在了窗外的雪地上，而小兔子，已经稳稳地待在温暖如春的屋子里了。
小朋友，不管白天走了多少弯路、做了多少事，现在你也已经平安回到家、回到小床上啦。让走过的路留在身后，舒服地躺好，晚安。
