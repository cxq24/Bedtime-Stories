# 第079集：安静也能一起玩

主题：陪伴可以不填满声音

小朋友们，准备好听故事了吗？今天的故事叫《安静也能一起玩》。雨后的安静时光里，点点和皮皮不用说很多话，也能一起玩吗？

平时课间休息的时候，森林学堂的操场上总是热闹非凡，大家一起玩老鹰捉小鸡、跳皮筋，笑声和欢呼声一刻也不停。
不过今天下午放学后，下了半天毛毛细雨的森林格外宁静。小鼹鼠点点带着一本新借来的无字图画册，来到皮皮家的小木屋做客。

他们没有在客厅里跑闹，而是搬来两把小木椅，并排坐在卧室靠窗的小桌边。
那本厚厚的无字小画册，平平展展地摊开在他们两个人的中间。画册上没有一个字，全是用柔和的水彩画出来的森林四季风景。谁也没有急着开口去大声讲故事，屋子里安安静静的。

第一页画着一座弯弯的石头小桥，清澈的桥洞下，正漂过一片小小的红树叶。
小鼹鼠点点伸出毛茸茸的小爪子，轻轻指了指桥下的那片红树叶；坐在一旁的皮皮看懂了，微笑着轻轻点了一下头，又用手指了指桥栏杆上停着的一只小蜻蜓。

就这样，他们不需要用嘴巴说很多话，只要一个眼神、一个手势，就能明白对方看到了什么有趣的小细节。
看完这一页，皮皮伸爪轻轻翻到下一页。翻过书页之后，两个人都没有急着往下指，而是一起停下来歇了一会儿，竖起耳朵，静静地听着窗外被雨水洗过的树叶，在微风里“沙沙”地轻轻挨着树叶。

整座小木屋没有像平时做游戏时那样变得热热闹闹，可是你看，在温暖的窗灯下，有两双放松的小爪子，正安安静静地靠在同一张小木桌边。这份不说话的默契，让人心里觉得无比踏实、无比温暖。
一直看到画册的最后一页，天色已经完全黑了下来。点点拿来一条布书签夹好，皮皮则轻轻合上画册的封皮，起身把好朋友送到了门廊门口。

点点挥挥手回家去了。那段没有说很多话、却格外美好的傍晚时光，留在了窗边的小木桌上，也稳稳地留在了皮皮暖暖的心窝里。
洗漱完毕，皮皮钻进暖黄色的毛毯里，把胡萝卜玩偶抱在身边，特意在枕头旁拍了拍，就像是给刚才那份舒服的“安静”，也在床上留了一个专属的小座位。

皮皮的眼睛慢慢闭合。此时此刻，房间里的声音很少很少，可是那种被好朋友和温暖包围着的陪伴感，却一点儿也不少。
小朋友，好朋友在一起的时候，不一定要一直热热闹闹地说话；今晚睡觉的时候，你也可以安安静静地待着，让喜欢的小伙伴轻轻陪着你。晚安。
