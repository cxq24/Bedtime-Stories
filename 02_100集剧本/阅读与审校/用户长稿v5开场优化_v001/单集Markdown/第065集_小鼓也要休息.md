# 第065集：小鼓也要休息

主题：把热闹温柔地收住

小朋友们，准备好听故事了吗？今天的故事叫《小鼓也要休息》。草地音乐会排练结束后，小鼓怎样把热闹轻轻收起来呢？

森林学堂一年一度的“夏日草地音乐会”就要到了，皮皮在班级乐团里担任神气的小鼓手。
今天下午，小松鼠团团和小鹿芽芽来到皮皮家院子里一起排练。皮皮把他的红边小圆鼓挂在胸前，手里握着两根圆头小木槌，“咚哒、咚咚哒”，敲出了整齐又欢快的节奏，伙伴们跟着鼓点拍手唱歌，热闹的笑声传出去老远。

傍晚送走朋友们后，皮皮把小圆鼓带回屋里，随手放在了卧室游戏角的软地垫上。
吃过晚饭，洗完热水澡，夜色已经完全笼罩了森林。皮皮走进安静下来的卧室，一眼就看见了还摆在地垫中央的那面小圆鼓。

白天的时候，小圆鼓可精神啦，鼓面紧绷绷的，每一次木槌落下都会发出洪亮的声响；可是现在到了晚上，屋里静悄悄的，小圆鼓孤零零地待在地垫上，白色的鼓面在柔和的灯光下显得安安静静的，好像也有点儿累了。
皮皮蹲到地垫旁，伸出小爪子，把散落在鼓边的两根圆头小鼓槌轻轻拿了起来。

这回，他没有再举起鼓槌去敲哪怕一下鼓面，而是拿来一只细长的绒布小袋子，把两根辛苦了一下午的小鼓槌平平地放进去，让它们并排躺在软布袋里休息。
接着，皮皮拿来一块干净干燥的软布巾，顺着小鼓红色的木头边框，轻轻擦去了白天沾上的草屑和手印；然后双手稳稳地抱起小圆鼓，把它放回了墙角低低的专属木架上。

放好之后，皮皮还觉得不够妥帖，又从篮子里找出一小块透气的纯棉方布，轻轻盖在了白色的鼓面上，看起来就像是替忙碌了一整天的小圆鼓，拉好了一条轻柔的小被子。
随着棉布落下，卧室的游戏角彻底不再忙碌了。白天那个叮咚作响、热热闹闹的地方，终于也有了属于它自己的一小块安静夜色。

皮皮把软地垫的边角铺平，慢吞吞地走向自己的小木床，连踩在地板上的脚步声，都比刚才还要轻柔了一点。
他钻进被窝，抱好胡萝卜玩偶，把两只小爪子平放在暖黄色的毛毯上，手指不再跟着白天的音乐节奏轻轻拍打。

皮皮的眼睛闭上了，两只长耳朵也彻底放松下来。原来，那个白天最喜欢热闹鼓点的小兔子，到了晚上，也同样喜欢这份无人打扰的、舒服的安静。
小朋友，今天玩过的热闹游戏、听过的欢快音乐，都可以先盖上小被子歇一会儿啦。现在，让安静温柔地陪着你，慢慢睡去吧。晚安。
