# 第055集：蝴蝶停在叶背

主题：从飞舞到停歇

小朋友们，准备好听故事了吗？今天的故事叫《蝴蝶停在叶背》。蝴蝶在花间飞了一会儿，最后会停在哪里休息呢？

春天的花园里热闹极了，五颜六色的花朵全都开了。
今天下午，皮皮和小刺猬栗栗、小鹿芽芽在屋后的花草地上玩了好久。草地上飞舞着许多漂亮的柠檬黄小蝴蝶，它们一会儿落在这朵蒲公英上，一会儿又飞到那丛紫云英上，薄薄的翅膀在阳光下一扇一扇的，好像永远也不知道疲倦。

大家追着蝴蝶跑呀、看呀，笑声洒满了整片草地。
直到太阳慢慢沉到西边的树林后面，天空中亮起了第一颗朦胧的暮星，热闹的花草地才渐渐安静下来。伙伴们各自回了家，皮皮也洗干净手脸，回到了自己的卧室里。

在拉窗帘之前，皮皮往窗外花坛里那株宽叶紫丁香上看了一眼，忽然轻轻地“呀”了一声。
只见在一片宽宽大大的丁香树叶背面，正停着一只柠檬黄色的小蝴蝶！也许它就是白天在草地上和皮皮一起玩耍的那只吧。

白天的时候，它的翅膀总是张得大大的，在花丛间飞了那么久、那么远；可是现在到了傍晚，它把两片柠檬黄的翅膀慢吞吞地、整整齐齐地合拢在了一起，竖在背上，看起来就像一片安静的黄叶芽。
丁香叶背面那些凸起来的、细细的叶脉，就像一条防滑的小木梁，刚好稳稳地托住了小蝴蝶纤细的六只小脚，而宽大的叶片则像屋檐一样，在它头顶挡住了夜里的露水。

皮皮看得入神极了，他下意识地想推开玻璃窗，凑近一点跟小蝴蝶打个招呼。
可他的小爪子刚碰到窗栓，就温柔地停住了。他知道，如果现在打开窗户，屋里的灯光和流动的气流就会惊扰到它，说不定会让这只已经累了一天的小蝴蝶，不得不在黑夜里重新飞起来。

于是，皮皮不仅没有开窗，还把窗边那把小木椅往后轻轻挪开了一点。隔着透明的玻璃窗，远远地看上一眼，就已经能清清楚楚地感受到这份美好的停留了。
窗外的丁香叶子随着晚风轻轻晃动，叶背上的小蝴蝶没有再起飞，它把翅膀收得稳稳的，安心地进入了梦乡。

皮皮转身走到书桌前，也把自己白天画画用过的小画纸整整齐齐地收进抽屉里。白天的飞舞、奔跑和忙碌，到了这一刻，全都可以像合拢的蝴蝶翅膀一样，慢慢停下来了。
他钻进暖黄色的毛毯里，把两只长耳朵轻轻放好，让胡萝卜玩偶贴着自己温暖的爪心。

窗外的绿叶背上，歇着一双飞累了的小翅膀；屋里的软木床上，歇着一只玩累了的小兔子。皮皮的眼皮越来越沉，慢慢地闭上了眼睛。
小朋友，今天你已经像小蝴蝶一样，快乐地飞舞、探索了一整天，现在不用再飞得很远啦。把小手小脚收进被窝里安顿好，舒舒服服地休息吧。晚安。
