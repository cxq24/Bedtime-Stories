# 第060集：春风把窗合轻

主题：结束活动时保留温柔

小朋友们，准备好听故事了吗？今天的故事叫《春风把窗合轻》。夜风吹起窗帘时，皮皮怎样轻轻把窗合好，又留住春风的温柔呢？

春天的夜晚，风是软绵绵的，带着淡淡的青草和丁香花的气息。
今天晚上睡觉前，皮皮靠在床头看了一会儿图画书。半开的木窗户里，一阵温柔的春风吹进来，把窗边的叶子花窗帘轻轻托起，吹成了一个圆润好看的小弯弧。

看完了最后一页书，皮皮打了个哈欠，放下书本，准备去把窗户合上睡觉了。
他走到窗边，伸出小爪子握住木窗的把手，往中间轻轻一拉。就在两扇窗框快要合拢的时候，皮皮忽然觉得手底下有一点点软软的阻力，窗户没有像平时那样顺畅地贴合在一起。

皮皮没有使劲去推窗栓，而是立刻停住了手，低头仔细检查了一下。
原来，刚才春风吹动窗帘的时候，有一小截浅绿色的窗帘布角太调皮了，还留在窗框的缝隙边上，差一点儿就要被合拢的窗户紧紧夹在外面了！

皮皮笑了笑，幸好自己没有急匆匆地用力关窗。
他先把木窗户往外稍微推开一点点，留出宽松的空当；然后用另一只小爪子，把那一小截夹在边上的窗帘布角，顺着布纹慢吞吞地、温柔地理回了屋里。

等窗帘乖乖地垂在窗台内侧后，皮皮这才重新握住窗把手，让两扇木头窗框轻轻地、缓缓地靠拢在一起，“咔哒”一声轻响，窗栓稳稳地扣好了。
整个关窗的过程，没有发出一丁点儿急促或者生硬的碰撞声。屋里的叶子花窗帘柔软地自然垂下，没有哪一角被拽得紧紧的；而窗外的树叶依然在春风里轻轻摇晃。调皮的春风，就这样被礼貌地留在了它自己的花园小路上。

皮皮把窗边的小木椅推好，转过身回到温暖的床边。窗边收尾的小事情，已经被他用最温柔的方式做完了。
爬上床钻进被窝时，皮皮也用同样温柔的动作，把暖黄色毛毯的被角理得松松软软的，让里面的小脚丫和外面的长耳朵，都有最自在、最舒服的地方。

胡萝卜玩偶静静地靠住他的手臂，皮皮慢慢闭上了眼睛。此刻的房间，就像那扇刚刚被轻轻合好的木窗一样，妥帖、柔和又安静。
小朋友，在结束今天所有活动的时候，也让我们把动作放轻、放慢吧。把今天轻轻合好，让明天的故事留在明天，现在，安心休息，晚安。
