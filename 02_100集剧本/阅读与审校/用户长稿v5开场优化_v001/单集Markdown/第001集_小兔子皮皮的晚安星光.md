# 第001集：小兔子皮皮的晚安星光

主题：在熟悉的陪伴里放松与入睡

小朋友们，准备好听故事了吗？今天的故事叫《小兔子皮皮的晚安星光》。我们陪皮皮一起看看夜里的小星星。

夜深了，森林里的小屋，亮着一盏暖暖的小灯。
小兔子皮皮靠在枕头上，盖着他的小毛毯。

窗外，月亮弯弯的，树叶轻轻摇。

皮皮揉揉眼睛，打了个小小的哈欠。
他把长耳朵轻轻放好，小爪子也放松了。

小毛毯软软的，一直盖到下巴。

窗边的一颗小星星，慢慢亮了起来。
皮皮望着它，在心里轻轻说：小星星，晚安。
小星星安安静静地，陪着他。

皮皮抱好胡萝卜玩偶，往被窝里缩了缩。
小脚丫暖暖的，小肚子一起，一伏。

风轻了，树叶也慢慢安静下来。

小兔子闭上眼睛，安心地睡着了。
小朋友，你也可以找个舒服的姿势。

轻轻闭上眼睛。
小被子陪着你。
晚安，做个甜甜的梦。
