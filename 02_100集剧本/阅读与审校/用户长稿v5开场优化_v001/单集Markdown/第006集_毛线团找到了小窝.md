# 第006集：毛线团找到了小窝

主题：收拾也能轻柔而从容

小朋友们，准备好听故事了吗？今天的故事叫《毛线团找到了小窝》。一团滚乱的毛线要怎样才能安稳下来呢？

今天的树洞教室特别热闹，因为山羊老师带来了一大篮子五颜六色的毛线团，有天空一样的蓝色，草地一样的绿色，还有太阳一样的暖黄色。
大家要一起用毛线，在纸板上贴出自己最喜欢的东西。

小松鼠团团最心急，他抱起一个红彤彤的毛线团，想剪下一大段来贴大松果。可是小爪子一滑，“骨碌碌——”红毛线团掉在地上，顺着木地板一直滚到了滑梯下面，拖出了一条长长的红尾巴。

团团追着毛线团跑过去，结果脚丫不小心缠在了毛线里，越着急，线就绕得越乱，急得他的大尾巴都耷拉下来了。
皮皮看见了，放下自己手里的黄毛线，迈着小步子走过去，轻声说：“团团，别急，我们不追它，我们坐下来慢慢绕。”

皮皮教团团先坐在软垫上，把线头放在爪心里，像哄小宝宝一样，顺着毛线团的肚子，慢慢绕了一圈。
绕一圈，地上的长线就短了一点。再绕一圈，毛线团又变得圆滚滚、胖乎乎的了。

不一会儿，乱糟糟的红毛线就全都收好了。团团开心地把毛线团放进铺着棉布的小竹篮里，还送给皮皮一小段暖黄色的毛线作为谢礼。

傍晚放学回到家，皮皮把那小段黄毛线和自己家里的毛线团放在一起。
吃过晚饭后，那个小毛线团也不小心从矮桌上滚到了床边，长长的一根线，轻轻拖在卧室的软垫上。

皮皮一点儿也不慌张。他想起白天在学校和团团一起收拾的样子，安安静静地坐在床沿，把线头放在爪心，慢慢地绕了起来。
一圈，两圈，三圈……呼吸也跟着绕毛线的动作，变得又轻又慢。

床边的小篮子里，正好躺着一块干净的棉布，像一个柔软的小窝。
皮皮把圆圆的毛线团轻轻放进去，把小小的线头藏在下面，这样它就不会在夜里牵着谁的小脚丫到处跑了。

篮子靠着椅脚，稳稳地停好。皮皮看了一眼，小爪子也跟着彻底放松下来。
窗外的晚风把树叶拢在一起，屋里的毛线，也已经收好了自己的小路。

皮皮钻进温暖的被窝，抱住胡萝卜玩偶。今晚不用再绕啦，小小的毛线团也在篮子里睡下了。
小朋友，把今天轻轻放到一边吧。没有收完的事，可以等明天。晚安，做个好梦。
