# 第097集：小屋里的轻声晚安

主题：用温柔仪式结束一天

小朋友们，准备好听故事了吗？今天的故事叫《小屋里的轻声晚安》。熟悉的小屋里有许多老朋友，皮皮会用怎样轻柔的仪式向他们道晚安呢？

夜深了，整座森林都进入了梦乡，皮皮的小木屋里也收拾得干干净净、妥妥帖帖。
今天晚上，洗漱完毕的皮皮坐在自己温暖的小床边，看着房间里这些陪伴了自己一天又一天的熟悉老朋友，心里涌起满满的感激。在钻进被窝之前，他想给今天陪过自己的每一件小东西，都轻轻地说一声温柔的“晚安”。

皮皮先转过头，望了望挂着叶子花窗帘的木窗户，轻声说：“晚安，小月亮。”
窗外的银色月光乖乖地停在窗框边上，像是听懂了皮皮的话，安静地洒下一层薄纱，没有急匆匆地闯进屋里来晃他的眼睛。

接着，皮皮又看了看书桌上整齐排放的笔架，轻声说：“晚安，小画笔，还有小画家。”
那支洗得干干净净的软毛小画笔，正平平地躺在木头笔架上，柔软的笔尖悬空歇着，今天它已经画出了最美的颜色。

然后，皮皮低下头，看了看床沿下方的小地毯，轻声说：“晚安，小拖鞋。”
那两只毛绒小拖鞋正鞋尖朝前，整整齐齐地并排坐在床下。皮皮把光溜溜、暖融融的小脚丫收进被窝里，让辛苦了一天的小拖鞋安心留在原处休息。

说完这些，皮皮伸出小爪子，轻轻摸了摸身后的大枕头，顺势慢吞吞地靠了下去。
软绵绵的大枕头虽然不会开口回答，却在皮皮靠上来的第一时间，就用最蓬松的怀抱，稳稳当当地接住了他的小脑袋和脸颊。

最后，皮皮把一直坐在旁边的胡萝卜玩偶抱回了自己的小臂弯里，替它，也替自己，拉过那条熟悉的暖黄色小毛毯，一直盖到下巴底下。
你看，小木屋里的每一件东西，从窗台到书桌，从地板到枕边，全都安顿好了。房间里不用再说很多热闹的话，却已经充满了满满当当、让人安心的陪伴。

皮皮慢慢地闭上眼睛，在心里把今晚最后一句、也是最轻柔的一句“晚安”，留给了这个同样认真生活、认真长大了一整天的自己：“晚安，皮皮。”
呼吸变得又轻又慢，小屋彻底安静了下来。

小朋友，现在也请你像皮皮一样，在心里给你的小枕头、小被子，还有今天表现得特别棒的自己，道一句温柔的晚安吧。你的小床已经等好啦，晚安。
