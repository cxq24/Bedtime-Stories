# 第086集：枕边的森林电台

主题：从倾听外界回到自身安静

小朋友们，准备好听故事了吗？今天的故事叫《枕边的森林电台》。森林电台传来轻轻的声音，听了一会儿以后，皮皮怎样回到自己的安静里呢？

前几天，小熊绒绒的爸爸修好了一台老式的木壳收音机。皮皮去绒绒家玩的时候，他们拧开旋钮，听到了“森林广播电台”里传出来的轻音乐和故事，皮皮觉得神奇极了。
今天晚上，皮皮洗漱完毕，早早地钻进被窝，侧着身子躺在柔软的大枕头上。

屋里关了大灯，一片宁静。皮皮竖起长耳朵听了听窗外，突发奇想地把今晚的整座森林，想象成了一座不插电的、很轻很轻的“枕边小电台”。
你听，节目已经开始了：窗外老橡树的树叶轻轻挨着树叶，发出的“沙沙、沙沙”声，就是电台里播放的第一首轻音乐小曲子；再往远处听一点，森林深处那条小溪缓缓流淌的声音，就像一条慢吞吞往前走的细线，在给音乐伴奏呢。

至于门廊下挂着的那串贝壳小风铃，因为白天已经用软棉布系好了，今晚正乖乖地歇着，没有加入这场广播。
皮皮听着听着，发现这座“森林电台”并不是每一秒钟都塞满了声音的。风停下来的间隙里，会留出好大一段没有任何声响的空白，可那段舒服的空白，听起来也格外让人安心。

皮皮没有从被窝里爬起来，去推开窗户寻找更多、更响的新声音；他只是保持着侧躺的舒服姿势，看着窗边那道早就留好的、窄窄的窗帘小缝。
又听了一小会儿，神奇的变化发生了——随着皮皮的困意越来越浓，窗外森林里的树叶声和小溪声，好像自己慢慢地往后退，挪到了很远很远的地方，音量被自动调到了最小。

相反，皮皮脸颊底下贴着的纯棉枕套的柔软布纹，还有怀里胡萝卜玩偶温暖的触感，反而变得离自己好近、好清晰。
皮皮把玩偶往怀里抱了抱，彻底松开了小爪子。他想：真正的森林电台到了深夜也是不用一直播放新节目的；当所有的曲子都播完之后，屋里这片纯粹的安静，本身就是最好听的晚安曲呀。

暖黄色的小毛毯随着皮皮的呼吸，轻轻地一起、一伏。房间里没有任何忙碌的动静，只有熟悉的、暖融融的夜晚包裹着全身。
皮皮慢慢闭上眼睛，把竖着听了一整天声音的两只长耳朵，也像关掉收音机开关一样，轻轻地、软软地放下来休息了。

小朋友，今晚的广播已经结束啦，你也不必再竖着小耳朵去寻找外面的新声音了。把注意力收回温暖的被窝里，让安静陪着你，晚安。
