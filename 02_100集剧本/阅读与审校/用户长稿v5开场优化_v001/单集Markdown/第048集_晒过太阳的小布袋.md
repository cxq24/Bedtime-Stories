# 第048集：晒过太阳的小布袋

主题：通过熟悉触感安心休息

小朋友们，准备好听故事了吗？今天的故事叫《晒过太阳的小布袋》。晒过太阳的小布袋，留下了怎样让人安心的暖暖触感呢？

今天中午是个难得的冬日大晴天，金灿灿的阳光毫无保留地照在小木屋向阳的窗台上。
皮皮在去森林学堂下午班之前，特意把自己枕头边那只装满干薰衣草和棉花的小布袋，放在了向阳的窗台木板上，让它美美地晒一个日光浴。

到了傍晚放学回家，太阳虽然已经落山了，但当皮皮走到窗台边，把那只浅米色的小布袋重新抱进爪心里时，他惊喜地发现，布袋里好像还藏着白天太阳公公留下的温度！
小布袋的表面有一层细细的棉绒，摸起来又干爽又软糯，凑近闻一闻，除了淡淡的干花草香，还有一股只有晒过太阳才有的、蓬松又温柔的暖阳气息。

因为白天在窗台上放久了，小布袋里面的棉花团有一点点偏向了一边，让袋子的一角高高地鼓了起来。
皮皮坐在床沿上，没有使劲去拍打它，而是伸出两只小爪子，隔着柔软的棉布，把里面的小棉团一点一点轻轻拨松、揉匀，让那个鼓起来的小角，像做完体操一样，慢慢地躺平了。

到了睡觉的时候，皮皮把这只晒过太阳的小布袋，轻轻放到了自己大枕头的旁边。他没有把布袋压在身子底下，只是让它安安静静地陪在脸颊旁，只要一侧头，就能闻到那股让人安心的阳光味道。
皮皮望了一眼窗外，冬夜的雪色是清冷的浅蓝色；再看一眼屋里，床上的毛毯是温暖的鹅黄色。不同的颜色，都在这个夜晚慢慢地歇息着。

皮皮先抱起自己的胡萝卜玩偶放进怀里，接着又伸出小爪子，轻轻摸了摸枕边那只软糯的小布袋，然后才心满意足地把爪子放回了被窝里。
软软的小枕头托着脸颊，暖黄色的毛毯裹着脚丫，身边围绕着的每一件东西，都是那么熟悉、干爽又柔软。

皮皮闭上眼睛，再也不需要去屋里的其他地方寻找什么了，因为今天最顶级的舒服，已经完完整整地待在这里了。
小朋友，你的小被子和小枕头，是不是也有一种你最熟悉的、香香软软的味道呢？让熟悉的小被子紧紧陪着你，轻轻靠好，慢慢休息吧。晚安。
