# 第078集：把小印子擦轻

主题：容许一点不完美留着

小朋友们，准备好听故事了吗？今天的故事叫《把小印子擦轻》。画上的小印子擦不干净，留下一点点不完美也可以吗？

随着画画的本领越来越熟练，皮皮最近开始尝试不用尺子，直接用铅笔徒手画小木屋的建筑线条了。
今天晚上睡前，皮皮坐在暖融融的床头灯下，在一张厚实的白色素描纸上，画自己最心爱的小木屋。

他画得很专注：圆圆的木门、挂着叶子花窗帘的窗户、还有门廊下的小台阶，全都一笔一划地画得端端正正。
可就在最后画倾斜的木头屋顶时，皮皮手里的铅笔顺着惯性往外多滑了一小段——“哧”的一下，一条短短的多余铅笔线，正好从屋顶瓦片的旁边伸了出去，就像屋顶上长出了一根不听话的小呆毛。

皮皮停下笔，从文具盒里拿出一块干净的白色软橡皮，捏在爪心里，对着那条多余的短线轻轻地擦了擦。
擦过两遍之后，那条深色的铅笔线很快就变淡、消失了；可是因为素描纸有细细的纹理，在屋顶旁边的纸面上，还是留下了一小块极浅极浅的灰色小印子。

皮皮看着那块浅印子，举起橡皮，想再用力气使劲擦上十几下，把那块纸面擦得跟周围的雪白一模一样。
可是皮皮刚擦了一下，就发现如果再使劲摩擦下去，厚实的素描纸表面就要起毛、变薄，甚至有可能会被擦破一个洞，到时候整座画好的小木屋都要被毁掉了。

皮皮立刻停住了捏着橡皮的小爪子。他从笔筒里拿出一把软毛小刷子，轻轻地把纸面上细细的橡皮屑扫到桌角垃圾桶里，然后双手捧起画纸，放在灯光下端详了一会儿。
你看，屋顶边上那一点点极浅的淡印子虽然还在，可是整座小木屋也完好无损地立在纸上呀！窗户里透出的暖灯、圆圆的小门、还有门前的小花盆，没有一样因为旁边那点小印子而变得不好看；相反，那点浅印子看起来就像是夜空中飘过屋顶的一小缕薄云。

皮皮满意地把画纸平平放好。他觉得，让那一小块浅浅的印子安安静静地留在那儿，比把纸擦破要聪明得多。
他把软橡皮和铅笔收回同一只文具盒里，盖好盖子。今天的修改工作，到这里就圆满收尾了。

走到床边，皮皮钻进被窝，把暖黄色的毛毯拉好。他特意张开刚才一直捏着橡皮的小爪子，松松地搭在胡萝卜玩偶软绵绵的肚皮上。
皮皮闭上眼睛。画纸上的浅印子留在了画纸上，而小兔子今晚的轻松与舒服，已经完完整整地留在了被窝里。

小朋友，如果今天有一点点做错的小地方或者小瑕疵，轻轻改过就好啦，不必把每一点痕迹都擦得干干净净。对今天的自己温柔一点，安心休息吧，晚安。
