# 第003集：小枕头里的云朵

主题：找到适合自己的舒服

小朋友们，准备好听故事了吗？今天的故事叫《小枕头里的云朵》。我们看看皮皮怎样找到最舒服的枕头位置。

睡前，皮皮把小枕头拍了拍，枕面鼓起一个软软的小包，像朵小云。

他把一只耳朵放上去，云朵有点高；换个方向，又有一点点低。

皮皮没有急着躺好。
他把枕头转了半圈，慢慢拨松里面的棉絮。

窗外飘过一朵真正的云，也在月亮旁边，轻轻换了个位置。

皮皮看着它笑了。
原来，小云朵也会慢慢找，一个合适的地方。

他把枕头往里挪一点，让长耳朵自然垂下，小脑袋也稳稳地靠住。

这回，不高，也不低。
小枕头轻轻托着他，像接住一片落下的叶子。

皮皮闭上眼睛，把爪子放松。
窗外的云走远了，枕边的小云留下来。

小朋友，你也可以慢慢找到，自己的舒服。
枕头已经等好了。
晚安，做个软软的梦。
