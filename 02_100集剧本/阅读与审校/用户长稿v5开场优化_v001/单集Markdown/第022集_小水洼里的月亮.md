# 第022集：小水洼里的月亮

主题：看见变化而不必抓住

小朋友们，准备好听故事了吗？今天的故事叫《小水洼里的月亮》。雨后的水洼映出了月亮，月亮会一直停在那里吗？

傍晚的那场阵雨终于停了，空气里飘着泥土和青草被洗干净后的淡淡清香。
吃过晚饭后，小鼹鼠点点和皮皮约好在门廊前见一面，归还白天借走的彩色蜡笔。

送走点点后，皮皮站在门廊的台阶上，低头一看，发现台阶前那块微微凹下去的青石板上，积了一小汪浅浅的雨水。
更奇妙的是，天空中刚刚升起的那弯银白色的月亮，居然也掉进了这汪小水洼里！水洼里住着一弯小小、亮亮的月亮，正安安静静地望着皮皮呢。

皮皮好奇地蹲下身子，把小脑袋凑近了一点。水里的月亮好像也害羞地靠近了一点，在水面上闪着柔和的光。
皮皮刚想伸手去指给屋里的胡萝卜玩偶看，就在这时，一阵晚风吹过头顶的橡树，“啪嗒”一声，一片带着雨珠的树叶落了下来，正好掉进了小水洼的正中央。

水面晃动起来，原本圆整又清晰的月牙儿，一下子碎成了好几条弯弯曲曲的银线，左右摇晃着，怎么看都拼不回刚才的样子了。
皮皮伸出一半的小爪子停在半空，心里有一点点着急，想伸手去把那片捣乱的树叶捞出来，帮小月亮扶稳。

可是皮皮转念一想：白天在科学角玩水盆的时候，手越是在水里搅动，水波就会晃得越厉害呀。
于是，皮皮收回了小爪子，把双手抱在膝盖上，稳稳地坐在门廊的台阶上，耐心地等待水面自己安静下来。

一秒，两秒，三秒……水洼里的波纹一圈一圈往外散开，越来越浅，越来越慢。
过了一小会儿，水面重新变得像镜子一样平。那弯被打散的小月亮，又一点一点聚拢在了一起，恢复了安静明亮的模样；而且呀，在月亮旁边，还多了一片像小船一样的绿叶子陪着它呢。

皮皮看着这一幕，开心地笑了，拍拍裤子站起身来。原来，天上有月亮，水里也有月亮，它们都不需要被抓在手里，留在原处就已经足够美好了。
他关好小木门，回到干燥温暖的小床上，把微凉的小脚丫收进暖黄色的毛毯里。

窗边的月光轻轻落下来。皮皮闭上眼睛，不再去等外面的每一条水波纹停好。
小朋友，如果今天你的心里也有过像小水洼一样摇晃、着急的小心情，没关系，不用去抓它，只要安安静静地躺下来，心里的水波就会慢慢平静的。晚安。
