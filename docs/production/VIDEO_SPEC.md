# 视频制作规范

版本：2.5｜更新：2026-11-13（北京时间）。加入逐镜因果与物件连续性检查；已验收基准：第001集第二版；当前用户长稿完整口播、不限五分钟、可变分镜，历史样片不限制新集镜数。

## 画面风格与角色

- 竖屏9:16，单幅满版儿童绘本插画，手绘水彩、细纸纹、圆润简洁造型。
- 水彩保持柔和对比；按v5分镜所描述的地点、时间和天气选色，夜景可用暖琥珀灯光与灰蓝夜色。
- 图片中不生成文字、字幕、字母、商标、水印、拼贴边框；避免写实皮肤、3D塑料感、荧光、高对比惊吓表情。
- 皮皮固定为小灰兔、圆脸、粉鼻、自然下垂长耳，深蓝星星帽与黄色帽球。暖黄毛毯和橙色胡萝卜玩偶是初版卧室场景的道具。
- 历史卧室场景的家具布局只适用于对应旧镜头，不作为新集模板。v5分镜需明确本集地点、空间关系及角色动作；同一连续场景保持布局一致。角色外形按[角色图库](../../03_素材与参数/用户长稿v4角色图库.json)实际加载参考。
- 为拼音字幕预留x72–1008/y1312–1668的低细节区域，人物脸部、关键动作与道具尽量位于其上方；字幕块需要上移时同步看图校正，不机械遮住主角。
- 参考图用途应区分角色身份、画风和场景布局。户外画面可借角色图锁定皮皮身份，不复制卧室家具。
- 用户长稿v5采用[角色图库规范](CHARACTER_LIBRARY_SPEC.md)和对应角色索引。身份外形固定，服装可按场景活动变化；同一连续场景保持服装一致。每镜实际加载对应角色身份图并记录版本，不能只靠文字描述。

### 角色表情与微表情（逐镜必做）

- 角色外形、年龄感、毛色、五官比例和身份特征保持稳定；**表情表演不固定**。不得把皮皮或其他角色长期画成忧郁、困倦、呆滞、微笑等同一种默认表情。
- 逐镜回到该镜对应的剧本文字和情节，判断角色此刻的情绪、注意对象和与其他角色的关系，再安排表情。按需体现于眉眼、眼神方向、瞳孔、嘴角、耳朵角度、头部倾斜、肩背和爪子姿势。
- 开心、好奇、担心、难过、惊讶、失望、安心、满足等状态应有可读但克制的差异。哭泣、张嘴大笑、强烈惊恐等幅度较大的表演，只在剧本明确支持时使用；温柔绘本风不等于所有角色都面带忧郁或微笑。
- 每个角色分别表演：同一事件中，安慰者、被安慰者和旁观者的目光与表情可以不同。情绪随剧情节点变化，不为制造变化而随机切换；同一连续动作或镜头内保持神情连贯。
- 角色参考图只锁定身份、造型和画风，不代表本镜表情。提示词必须描述当镜情绪和可见表演；若参考图带有默认忧郁/困倦神情，应明确要求按本镜剧本替换该神情，同时保留角色外形。
- 静态插画选取本镜最能代表当下情绪的瞬间；如果长段落中情绪确实发生转折，分镜应在有文本依据的转折处切换状态或拆镜。

## 分镜与镜头运动

- 已验收样片的九镜只用于历史复现。用户长稿先按[分镜规范](STORYBOARD_SPEC.md)做完整草案，以真实口播校准、锁定后逐镜配图；数量随剧情和实际时长变化，不再固定九张。
- 通常约8–10秒换图，尽量不超过15秒；短动作或语义变化可3–5秒切换。不机械按秒切图，不用重复近似画面填时长；原文、人物互动和状态变化决定画面。含叠化的实际可见时长一并记录和检查。
- 按最新用户反馈，镜头内使用固定图片，不做推拉、缩放、平移、星光闪动、呼吸形变或其他局部微动。一次等比裁切后位置保持不变；镜头之间仍采用0.96秒叠化。历史JSON中的motion=camera/local与微动建议不作为新片执行指令。
- 新图片必须对应本镜台词和动作。不得用九张样片图、重复占位图或不相关素材冒充已完成分镜。
- **跨镜连续性作为出图和渲染门槛**：同一个剧情物件用同一 `asset_id`、同一标准参考图和明确状态贯穿全片；角色离场后更新在场名单和地点，不能在后续镜头无交代地出现。出图前先核对逐镜前后状态和动作因果，出图后用全片接触表追踪物件外观、角色位置、进出场与状态变化。具体字段和流程见[分镜规范的跨镜连续性要求](STORYBOARD_SPEC.md#跨镜连续性与叙事逻辑出图前必做)。发现不一致先修分镜/图片，审查通过后再合成。

## 时间轴与转场

- 统一25fps；镜头边界对齐1/25秒帧格。先测量真实语音，再安排镜头，不能先定片长后压缩旁白。
- 转场采用0.96秒叠化（24帧，前后各0.48秒）。渲染片段长度需预留重叠：首镜加0.48秒，中间镜各加0.96秒，末镜加0.48秒；音频主时间轴不缩短。
- 2026-11-11已实际比较同为0.96秒的线性与缓入缓出叠化，保留现有线性默认；备选没有明显整体优势，也不能消除中点双影。详见[评估](../../03_素材与参数/角色参考图库/v4/初始化与转场评估_v001/转场评估/转场评估.md)及`03_素材与参数/静态转场配置.json`。图片衔接优先通过构图、光线和语义切点协调，字幕独立呈现。
- 末段最后4秒渐暗到 `0x182232` 深夜蓝。字幕逐句按真实音频时长定位，检查顺序、不重叠、不越出视频。
- 用户长稿v5以采用稿全部口播为准，超过五分钟也保留，不删文或变速控制片长。开场和尾声计入总长；镜间叠化在音频主时间轴内安排。旧v3约120秒只适用于历史稿件。

## 音床

沿用稀疏柔和的分解音与极轻低通环境声。音乐约每12秒换和声，音符间约2.7秒；不加入鼓点、突然高音或叮铃爆点。使用与人声等长的音床，音乐/环境声前2秒淡入、末5秒淡出；人声始终清楚可辨。

## 导出

| 项目 | 默认值 |
| --- | --- |
| 画幅 | 1080×1920，9:16 |
| 帧率 | 25fps |
| 视频 | H.264/libx264，CRF 20，preset veryfast，yuv420p，SAR 1 |
| 音频 | AAC 128kbps，48kHz |
| 封装 | MP4，faststart |
| 字幕 | 发布版烧录逐字拼音字幕，另交ASS、兼容SRT、字级JSON与无字幕母版 |

新片必须按[字幕规范](SUBTITLE_SPEC.md)叠加可见的逐字拼音，短语切换独立于图片切换；按[封面规范](COVER_SPEC.md)输出独立统一封面，封面不计入剧情图数量。先完成无字幕画面、叠化和渐暗，再叠字幕，避免字幕随场景叠化重影。末句后清空字幕。历史首集无烧录字幕仅保留为旧版基准。

中间无声片段建议CRF 18。不同平台如要求其他规格，另行导出平台副本并保留主母版。

## 检查

技术检查：完整解码；尺寸、帧率、帧数、时长与时间轴一致；音频无削波；字幕合法并与真实语音对应；实际分镜要求的所有原图齐备且无黑帧、拉伸、错误裁切或边缘黑线；检查图片可见驻留，尽量不超过15秒；同一镜头前后位置、尺度与构图不变，角色脸部、眼睛和道具稳定，服装变化有场景依据。逐镜核对角色表情、视线与姿势是否对应台词情节，确认没有跨全片复用同一种忧郁/困倦默认神情，也没有无文本依据的夸张表演。再对照接触表和 `continuity.json`，逐镜确认固定物件没有漂移替换、角色没有无交代瞬移、离场后没有错误留在原地，动作结果与后续镜头状态一致；未完成这项检查不记录为完整技术通过。

人工检查：完整听看声线和拼接、句尾、留白、音乐音量、台词与画面对应、镜头切点、末段淡出。报告必须分开记录技术通过与人工听看结果。

新增技术验收：独立封面1张与剧情原图分开计数；拼音覆盖每个汉字，调号完整、上下对齐、无字幕重影；发布MP4直接播放有拼音字幕。手机缩至360px宽检查标题、字号、长音节和两组字幕。
