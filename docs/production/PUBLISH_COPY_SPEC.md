# 三平台标题与正文交付规范

版本：1.1｜2026-11-16（北京时间）。每集完整交付视频、封面，以及抖音、小红书、微信视频号三份标题和正文，**每份正文中必须含标签**。新增用户要求：动作型标题、封面与标题统一、文案末尾用具体感受邀请交流。

## 文件与内容

每集交付`发布文案.md`，按“抖音／小红书／微信视频号”分三个部分，每部分有标题与可直接复制的完整正文。标题以具体人物和动作/发现为核心，优先点明皮皮正在做什么或遇见什么（如“皮皮看窗边的月亮”），避免只有抽象意象或物件名。封面上的主标题、项目的封面标题及三平台标题使用完全相同的文字；如需补充平台语境，将信息写进正文，不另改标题。封面底图无文字，排版后只显示这句主标题，不加账号或系列名。标题清楚自然优先，不为凑短字数而删掉人物或动作；最多8个汉字、最多两行，每行最多4字。

| 平台 | 默认写法（编辑目标，不是平台字数上限） |
| --- | --- |
| 抖音 | 使用统一标题；正文1–3句，简洁说明故事内容 |
| 小红书 | 使用统一标题；正文可稍详细，用2–4个短段描述情境、亲子阅读场景及本集特色 |
| 微信视频号 | 使用统一标题；正文自然连贯，适合家庭分享 |

每份正文末尾先写一段具体、真诚的第一人称感受，再用一个开放问题邀请观众分享自己的感受或经历；避免空泛的“好感动”“你觉得呢”。感受须指向本集真实细节（例如等待水面变平时那种慢慢松下来的感觉），并以创作者/讲述者的观察口吻表达，不编造现实生活经历。开放问题后放3–5个相关#标签：睡前故事/儿童绘本、亲子共读、具体故事物件或主题。根据内容选择，不堆热点，不使用无关标签；不以标签承诺平台流量。

## 与视频一致

描述当集真实故事，不剧透式编造新情节，不添加未呈现角色。拼音字幕可表述为“每个汉字上方配有拼音”，不宣传保证识字效果。避免“秒睡”“治愈失眠”等效果承诺；不加视频内口号、关注引导或教学跟读。

媒体制作前可以起草文案，明确标“初稿，待成片核对”；交付前核对视频、封面标题、拼音字幕是否真实存在，删除不符描述。三平台各有一份正文并不代表已经发布；平台发布需另有授权，实际平台链接和时间单独登记。

## 检查清单

- 三个平台均有非空标题与正文。
- 封面标题与三平台标题逐字一致，并清楚写出人物和动作/发现。
- 每份正文末尾有相关#标签，可整段复制。
- 每份正文在标签前以具体的第一人称感受和开放问题收尾，能自然邀请交流。
- 标题、正文、封面和最终剧情一致，描述的媒体特征已经实现。
- 发布前按平台当时界面的字数/话题规则调整；本规范不假设固定平台限制。
