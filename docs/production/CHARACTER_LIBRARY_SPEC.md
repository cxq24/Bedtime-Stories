# 角色参考图库规范

版本：1.1｜更新：2026-11-12（北京时间）。用户明确要求角色身份固定，允许按不同活动换衣服；每次出图实际引用对应角色图片。

## 固定身份与可变服装

第一批为皮皮及八位伙伴：栗栗、团团、绒绒、点点、芽芽、灰灰、米米、圆圆。姓名、物种、脸型、毛色／羽色、五官、耳朵、尾巴或背刺、特征斑纹及相对体型保持稳定。原文未指定的相对比例先标待设计，不以年龄推测。

服装与配饰可随活动、季节、天气和场景变化，如手工围裙、雨天雨具、户外衣物和睡前服装。毛色、脸型和身体比例不能随换装变化；同一连续场景不无故换衣服。帽子、围巾等为常用配饰，不能让它们成为唯一识别依据，也不能给其他角色套用皮皮的星星帽。

按原文情节安排换装，不为展示衣服增加旁白。原文明确描述的颜色、物件优先；未明示时可做合理视觉选择并记录，后续镜头沿用。

## 身份稳定，表情随场景变化

角色身份图是五官、毛色、体型、标记和整体画风的依据，不是所有镜头统一的表情模板。每镜依据剧本当前情节重新设计眉眼、目光、嘴角、耳朵角度、头部倾斜和身体姿态；皮皮及其他角色都不应长期使用忧郁、困倦、呆滞或微笑等单一默认神情。

情绪变化须有对应台词或动作支撑，幅度符合本系列温和绘本气质。根据开心、好奇、担心、难过、惊讶、安心等不同状态做清楚但不过度的区分；不添加原文没有的哭泣、惊恐或夸张大笑。多人同镜时，分别表达各自反应。角色身份参考和表情提示要分开写：身份参考锁定“是谁”，逐镜提示词说明“此刻如何感受和表演”。连续场景保持情绪与动作衔接，剧情确有转折时再改变表情。

## 图片和索引

登记入口：[角色图库索引](../../03_素材与参数/用户长稿v4角色图库.json)。图片目录：[角色参考图库/v4](../../03_素材与参数/角色参考图库/v4)。

先建立身份基础图，包含清楚的全身、脸部、正面与侧面或四分之三视角，再建立同框比例依据。换装图由身份基础图派生，分别保存服装ID及来源；换装参考不能替代身份参考。每份真实图片保存文件路径、角色ID、版本、摘要、来源、生成使用的参考图和审查状态。

2026-11-11首批专用参考图已生成：皮皮、八位伙伴及山羊老师共10张四视图身份表，另1张皮皮换装表和2张分组比例图，共13张PNG。已由助手逐张目视核对，文件和引用校验通过；用户已批准当前角色及主装用于制作。真实路径、摘要、提示词及版本见索引与[本次记录](../../03_素材与参数/角色参考图库/v4/初始化与转场评估_v001/RECORD.md)。其他配角仍需按实际入镜建立，不能因核心图库完成而标记全部配角都有图。

出图前运行`python3 local/character_references.py --characters <本镜ID...>`；有已建换装时加`--outfits pipi=day_v001`。将返回的`referenced_image_paths`实际传入图像工具；本工具会拒绝缺图、摘要变化、未知角色或超出单次5张参考上限的请求。它只完成加载预检，不自动调用图像模型。多人镜头须先准备明确覆盖入镜身份的组合参考，不得静默省略人物。

## 逐镜使用

1. 读取分镜的入镜角色ID，从索引查到对应实际可读的身份图。
2. 实际向图像工具传入所有入镜角色所需参考图；只写姓名或外形文字不算完成引用。多角色较复杂时可建立已核对的组合参考，记录它的原始角色图来源。
3. 同时使用该镜服装、地点和道具依据，区分身份参考、服装参考、画风参考与构图参考，避免把参考图的卧室背景一并复制。
4. 检查生成结果的脸、五官、颜色、斑纹、大小和服装。失败图保留为候选或弃用，不覆盖身份基准。
5. 每镜依据对应剧情检查角色表情和视线，不让身份图里的默认神情覆盖剧本表演；连续镜头情绪要连贯，文本转折处才改变。
6. 只有实际图片存在且完成检查后才登记可用。缺少角色图时，先准备该角色的参考素材，不用不相干动物或重复剧情图代替。

## 配角与无名动物

山羊老师、猫头鹰阿姨、喜鹊邮差叔叔及家人按实际入镜分别建立身份。猫头鹰阿姨不等于圆圆；熊爸爸、熊妈妈不等于绒绒；皮皮和团团的外婆不自动合并。

只有称谓的角色先用内部ID，不擅自起口播姓名。015无名蜗牛暂存为独立ID，不强行映射“慢慢”；小蝴蝶、小燕子维持自然小动物形态。书中人物或纸影道具另作画中／道具资产，不默认新增常驻伙伴。
