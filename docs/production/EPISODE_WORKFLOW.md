# 单集制作流程

一次只处理用户指定集数或批次。先读取[制作主控](../../CHANNEL_MASTER.md)的最新要求，再直接完成视频、封面和三平台含标签文案；常规事项不逐项确认。当前可参考001 v005的制作流程，运行信息见[交接](../../HANDOFF.md)。

## 1. 锁定内容和状态

读取主控、台账、目标集JSON/阅读视图与共用参数。核对集号、稿件版本、是否已有占用任务及已有媒体。建立本集RECORD并同步主控/台账；改稿只改JSON再同步阅读视图。故事不变时不重新选题。

新任务工程目录为`episodes/epNNN/vNNN/`，最终交付另存`Outputs/YYYY-MM-DD/epNNN-vNNN/`，日期按北京时间、任务名独立，保留`RECORD.md`、`images/`、`audio/`和`tools/`。当前历史参考工程为`episodes/ep001/v005/`；下一集需读取目标集JSON并适配台词、图片、时间轴和文案，不把001素材充当新剧情。原04/05目录为历史包约定。

## 2. 配音与实测时间

按[声音规范](VOICE_PROFILE.md)使用晓晓`-35%/-2Hz/+0%`逐句合成，保存源MP3、文本、实际参数和缓存摘要。先试听代表片段，再合成全篇；检查错读、空音频与句尾，以真实解码音频和JSON停顿编排时间轴。

## 3. 正式分镜、逐镜插画、角色表演与独立封面

先覆盖完整口播，再用真实音频锁定可变分镜；通常8–10秒，含叠化的图片可见时长尽量不超过15秒，动作变化可用3–5秒。正式出图前建立`continuity.json`，为持续出现的剧情物件分配固定ID，并逐镜记录角色所在地点、入离场、物件位置/持有者/状态、动作前后状态及承接的前镜；顺序复述全片动作因果并检查物件外观没有无依据变化。文字状态审查通过后才生成图片。重复物件每次使用同一标准参考图和外观锚点，按镜号生成后拼全片接触表，复核物件、角色位置、在场名单和动作结果，修正所有不一致再渲染。按实际镜数逐张生成，记录原始尺寸、来源、提示词及实际加载的角色参考。每个镜头都按当下台词标注入镜角色的情绪、表情、视线和姿态；角色身份保持统一，但不得把参考图的忧郁、困倦或微笑表情当成固定模板。情绪表现从眉眼、嘴角、眼神方向、耳姿和身体姿态中选择适合的细节，保持温柔自然；不添加剧本未支持的情绪。长段落情绪发生转折时，在对应语义节点安排画面状态变化。按[封面规范](COVER_SPEC.md)另交1张封面：选本集内容图，套用固定模板，替换默认四字、必要时五或六字的短标题。可以复用本集原图作底图；封面框内只显示短主题，不添加账号名、系列名、副标题或其他文字，不能拿无关图或布局占位冒充封面成品。

## 4. 拼音字幕与预检

按[字幕规范](SUBTITLE_SPEC.md)从原稿生成逐字音节映射，人工校对多音字、轻声、变调与儿化，再按真实口播切成短语。保存字级JSON、ASS、兼容SRT；检查每字上方的拼音和汉字居中对齐。

先做约20秒代表片段，覆盖长音节、长短句、两组排版和深浅背景；用手机尺度检查76px汉字/48px拼音是否清楚，不能只检查电脑放大图。发现遮挡先改构图/字幕块位置或拆句，不缩成小字。首个真实模板样片记录为待审，不写成已获用户验收。

## 5. 合成和导出

以真实语音、停顿与语义决定镜头边界，按25fps、0.96秒叠化及预留公式渲染；各镜固定机位，图片不缩放、不平移、不做局部微动。先合成无字幕母版，再叠拼音字幕为发布版，保留完整原音轨。检查末句后字幕消失、约8秒尾声和末4秒渐暗。

导出`epNNN.mp4`（有拼音发布版）、`epNNN_clean.mp4`（无字幕母版）、`cover.png`及编辑源、全部逐镜原图、`continuity.json`、`voice.wav`、`mix.wav`、`episode.ass`、`episode.srt`、`subtitles.ruby.json`、`timeline.json`、`project.json`、素材/字体来源与检查报告，以及`发布文案.md`（三平台各自标题、正文与正文内标签）。

## 6. 三平台发布文案

按[文案规范](PUBLISH_COPY_SPEC.md)，分别交付抖音、小红书、微信视频号的标题和正文；每份正文末尾必须含标签。文案根据实际成片核对，不能只交一份通稿或将标签仅放在单独字段。

## 7. 验收与交接

完整解码，核对规格、帧数/时长、混音削波、逐镜图文对应、无边缘黑线、封面短标题与安全区、每字拼音覆盖及实际烧录显示。对照`continuity.json`和全片接触表逐镜检查同一物件的外观/状态、角色入离场和地点切换、动作因果与后镜结果；检查不通过先修后重渲染，报告写明结果。完整听看发布版，复查字幕发音、句尾、镜头、留白、音乐与尾声；技术检查和人工听看分别记录，用户未验收则标待审。

交付时同步主控、台账和本集RECORD的版本、阶段、证据路径与下一候选。返工沿用集号、递增版本，复用未变的音频和图片；只改封面/字幕不重新请求配音。交付不等于发布。

## 阶段证据

| 阶段 | 通过依据 |
| --- | --- |
| 剧本 | JSON及阅读视图一致、采用版本已记录 |
| 配音 | 全句真实可解码，错读与句尾试听通过 |
| 图片与表演 | 依正式分镜生成真实独立插画，逐镜对应剧情；角色外形稳定，表情与视线、姿态贴合当前剧情，且有实际加载的角色参考；`continuity.json`及接触表的物件/场景/角色状态和因果检查通过 |
| 封面 | 独立PNG与编辑源，短标题内容准确，模板与手机裁切检查通过 |
| 拼音 | 每字映射齐全，词语读音人工核对，字形与上下对齐通过 |
| 渲染 | 发布版、母版、字幕与时间轴实际生成 |
| 发布文案 | 三平台各有标题与正文，正文内含标签，和本集实际内容一致 |
| 技术 | 完整解码及规格/字幕/削波检查通过 |
| 人工 | 完整听看意见、日期与审片者有记录 |
| 用户验收 | 用户对明确版本的反馈或确认原话 |

每项可标未开始、制作中、待审、通过、需修改或受阻。未运行的检查标未执行，不用计划或占位文件充当完成证据。

目录以[目录规范](DIRECTORY_SPEC.md)为准：共用剧本、角色图库不放Outputs；日期目录只保留单集视频、封面和交付文本，工程源与来源证据保留在episodes。004 v001已获用户认可，作为当前长稿制作基准。
