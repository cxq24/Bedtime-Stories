# 用户长稿分镜规范

版本：1.3｜2026-11-13（北京时间）。依据用户对完整口播、可变换图频率、逐集片头、先做分镜及跨镜连续性的最新反馈。新制作采用用户长稿v5；历史成片复现沿用原工程。

## 角色表情和镜头表演

每镜都要根据对应的原文和情节，为每个入镜角色确定当下的表情与姿态。角色身份和外形按图库保持稳定；眼神、眉眼、嘴角、耳朵、头部角度、身体姿势及爪子动作随剧情变化。不能因为角色参考图常见忧郁或困倦表情，就将其作为全片默认神情。

分镜草案的“画面内容/动作”必须写清当镜角色在感受什么、看向哪里、表情和姿态如何呈现；复杂多人场景分别标注每个角色的反应。开心、好奇、担心、难过、惊讶、安心等表现要让观众能辨认，但符合温柔绘本气质，不夸张、不添加原文没有的情绪。情绪持续的镜头保持连贯；只有剧本出现情绪或关系转折时才相应改变。静态图表现该节点最有代表性的瞬间。

角色参考用于锁定身份与画风，不作为表情模板。生成提示词须另外写本镜表情、眼神和肢体线索；如果身份参考的神情与剧本不符，明确保持角色外形、改用剧本要求的神情。

## 从剧本到画面

1. 从采用版本JSON读取全部口播。v5的唯一正文源是 `narration_paragraphs[].text`；标题、主题、镜头说明不读入口播。不得因镜数或时长删去正文、擅改年龄或添加新情节。
2. `p000`是本集专属开场口播，必须纳入配音、字幕、时间轴和覆盖检查；它的 `illustration_requirement: standalone` 要求单独制作一张或多张开场插画，独立于封面和第一张故事插画，不得复用后两者。
3. 先做完整分镜草案：标出每镜对应的原文段落与字串范围、地点、现实／回忆／想象／画中世界、入镜人物、主要动作和关键物件。片头也必须有自己的镜头与画面方案。可以先估时，但不能把估时写成真实秒数。
4. 按既定声音参数合成完整口播，测量真实语音和停顿。将每个镜头绑定实际语音范围；可在同一句中的自然语义处换图，不必等很长的整句结束。
5. 校准镜数、切点与转场，检查完整覆盖、画面驻留、服装与物件连续性。分镜内容和真实时间轴确定后，再逐镜生成合适的图片；不会因为尚未出图而把占位图登记成完成。
6. 合成时字幕独立按短语切换，一幅图可承载多条字幕；图片内部固定静止，镜间0.96秒叠化，25fps。最终完整听看台词与画面关系。

## 跨镜连续性与叙事逻辑（出图前必做）

分镜不是互不相关的单张插画。开始生成图片前，每集必须建立 `continuity.json`，作为该集唯一的跨镜状态表，并与锁定后的 `storyboard.json` 一起保存。最少包含：

- **固定物件表**：为剧情中会重复出现或改变状态的物件分配稳定 `asset_id`，记录唯一外观定义、尺寸/颜色/材质/显著细节、首次出现镜号、此后出现镜号、每镜位置/持有者/状态和参考图。比如同一块软垫不能在后续镜头变成懒人沙发、普通坐垫或其他家具；若原文没有写物件改变，就沿用同一 `asset_id` 和外观定义。
- **场景与角色状态表**：记录每一镜开始和结束时的地点、时间、入镜角色、角色位置、持有物、门窗等关键空间关系，以及角色是在场、离场还是画外。角色离开某地点后，后续镜头不得无交代地出现在另一地点；再次出现必须有台词或动作交代到达过程。不同地点间切换时，核对离场、路程/转场、到达和在场角色。
- **因果与状态变化**：对动作明确记录前置状态、动作、结果。例如“拿来地垫 → 铺在门廊 → 角色沿地垫行走”，不能跳到不相干物件；“客人告别离开 → 回到自己家 → 主角独自在卧室”须让在场名单随情节更新。省略不影响理解的路程可以用转场，但不能让角色或物件瞬移。
- **逐镜引用关系**：每镜记录 `continuity_refs`（引用的 `asset_id`）、`state_before`、`state_after`、`transition_from`（承接的前镜ID）；角色进出场与地点变化要在状态字段明确体现。稳定状态可引用前镜，不必重复写长段文字。

出图前做两遍检查：第一遍只看文字分镜，顺着镜号逐镜复述“谁在哪里、带着什么、刚发生了什么、下一镜为何成立”；第二遍检查所有固定物件的外观与状态有没有无依据改变。任何一个状态无法解释，都先修分镜和状态表，不进入出图。

图片生成时，把角色身份参考、相关场景参考和该物件的标准参考图一并提供；同一物件重复出现时引用同一参考，并在提示词里写清 `asset_id` 对应的外观锚点、当前状态及与前镜的关系。只重复文字描述不算完成连续性控制。若生成结果仍漂移，重生成或对已有图做定向修图，直到接触表中相邻镜头可辨认为同一物件；不能把不匹配的插画留到剪辑阶段再靠叠化遮掩。

每镜图生成后、合成前，按镜号制作全片接触表并进行**跨镜连续性审查**：逐个追踪重复物件、角色所在位置、在场名单和动作结果；同时对照口播，查找瞬移、物件变形/替换、状态倒退或结果未发生等问题。发现任一问题先修图或分镜，再渲染；检查记录写入本集的 `PRODUCTION_STATE.json` 或检查报告。技术解码通过不能替代这项审查。

## 换图节奏

- 镜数可变，不采用固定九镜或固定五分钟。通常约8–10秒换图，按场景与剧情需要可用3–5秒短镜，不把全片变成机械快切。
- 尽量让每幅图的实际可见时间不超过15秒。时间轴同时记录名义镜头区间与含叠化的可见区间；从图片首次出现到完全消失核查，超过15秒应拆分叙事节点或调整切点。不能只检查某幅图完全不透明的时间。
- 长段落需要拆成多个有内容差异的画面，而不是把同一句话硬停在一张图上。先后动作分别选关键状态；不让单幅静态图承担互相冲突的多个时刻。
- 同一地点可根据角色交流、动作结果、视线或关键物件改变构图。每幅图应增加可理解的信息，不能只重复床边、窗边或同一被角来填时长。
- 回忆、想象和书中场景遵循原文。例如085的海湾是想象，不能改成现实到海边；094远足是明天的计划，不能画成当晚已经完成。
- 末句后约8秒尾声也计入最后画面的可见时长。叠化在音频主时间轴内处理，不逐次延长或缩短口播。

## 每镜必须保存

| 字段 | 内容 |
| --- | --- |
| 镜头ID | 当集唯一且连续的编号 |
| 口播依据 | 版本、原文段落ID、正文范围；可跨段或在段内拆分 |
| 时间 | 估时／实际状态，实际起止，含转场可见起止与时长；未合成音频前实际值为空 |
| 场景层次 | 具体地点、时段、天气；现实／回忆／想象／画中世界 |
| 入镜角色 | 姓名和角色ID；被提及但不入镜的人物单独区分 |
| 角色参考 | 每个入镜角色实际加载的身份参考图路径、版本与来源 |
| 服装 | 服装ID、活动原因、与前后镜是否同一套；衣服变动不改变身份 |
| 画面内容/表演 | 构图、角色位置、明确动作或稳定状态、关键道具；逐个说明角色当下情绪、表情、视线和身体姿态 |
| 场景参考 | 对应地点与道具的参考版本，必要时记录前后状态 |
| 连续性引用 | `asset_id`、状态前后、承接前镜ID；详见本集 `continuity.json` |
| 素材与审查 | 提示词、真实原图路径和摘要、与口播是否匹配；缺图明确记未制作 |

## 检查边界

口播全部被覆盖，原文顺序无跳过、无重复朗读；镜头顺序与真实音频一致。画面可以为了叠化跨越切点，但不能因此重复音频。所有入镜角色有可用参考图，服装同场连续；原图和镜号一一对应。检查文字、脸、关键动作与字幕安全区，避免长拼音或两组字幕遮挡人物；逐镜检查表情是否响应对应情节，角色身份是否稳定，以及是否误把同一默认忧郁神情套用到大部分镜头。

本规范是执行要求，不是已完成分镜。v5 JSON中的 `storyboard.shots=[]` 表示未制作，不能拿旧九镜填充冒充新分镜。
