# 儿童逐字拼音字幕规范

版本：bedtime-ruby-v2｜2026-11-10。适用后续新片及明确要求重制的版本。用户要求**字幕每个汉字都带拼音**；发布MP4必须直接可见，不能只交独立字幕文件。

## 内容与拼音

1. 文本来自采用版本JSON：旧分镜稿为`narration_lines`，用户长稿v5为`narration_paragraphs[].text`；与实际完整口播一致，不显示镜号、提示词或额外教学内容。字幕按真实语音短语切换，与图片更换频率独立，一幅图内可以有多条字幕。
2. 每个汉字是一个布局单元，其正上方居中标一个完整拼音音节；声调使用Unicode调号，例如`wǎn`、`ān`、`lǜ`，不是`wan3`、`an1`、`lv4`。轻声不标调。
3. 按词语和上下文确定多音字、轻声与“一/不”变调，与实际普通话口播一致；三声连读保留词典本调标写。采用此标注约定并在全片保持一致；实际口播读错应返修音频，不为配合错读而改拼音。
4. “儿”独立读音标`ér`；儿化词按读音在前字音节加`r`，儿字上方仍标`r`并在JSON记为儿化关联，人工复核。人名、叠词、语气词逐项检查。
5. 标点不注音，保留中文标点；数字/符号如实际需要，应在采用稿中写成口播汉字并同步剧本，不能让注音器擅自改字。拼音仅供阅读，旁白不另读拼音、不加考试或跟读。
6. 可用支持词组的注音工具生成初稿，但逐句人工校对。未识别汉字、多音字不确定、缺失音节和字体缺字都不能通过质检；逐字列出待核对项。

## 字体、尺寸与位置

以1080×1920为基准等比缩放；面向学龄前及低年级儿童的制作默认值，须用修订样片在手机上检验。

| 项目 | 默认值 |
| --- | --- |
| 汉字 | Noto Sans CJK SC Medium，76px，暖米白`#FFF4DC` |
| 拼音 | Noto Sans Medium，48px，同色；需覆盖全部调号与`ü`组合 |
| 描边 | 深夜蓝`#182232`，汉字2px、拼音1px；不做闪烁和弹跳 |
| 字格 | 每格宽`max(96px, 拼音实测宽度+16px, 汉字实测宽度+16px)`；字与拼音各自居中 |
| 单行 | 一个“拼音＋汉字”组；优先每次4–7个汉字，内容总宽≤900px，标点计入实测宽度 |
| 行高 | 每组168px：拼音行盒58px、间距8px、汉字行盒86px，组间16px |
| 单组位置 | 拼音行盒顶部y1500、汉字行盒顶部y1566 |
| 两组位置 | 仅必要时使用：第一组y1332/1398，第二组y1500/1566；最多2组（4条视觉文本行） |
| 底板 | 随实际组数扩展；x72/w936，单组y1480/h188，两组y1312/h356；圆角24，深夜蓝72%不透明 |
| 安全边界 | 所有字形及描边在x90–990/y1312–1668内；底部至少252px留给平台UI；必要时整块上移，不压到脸/关键物件 |

字体的px指实际渲染尺寸。ASS中需设`PlayResX=1080/PlayResY=1920`并实测字体边界，不能假设另一引擎同字号像素完全一致。长音节如`chuāng`按实测扩格；超宽先按语义拆成下一条字幕，不能横向压缩拼音或缩成小字。

整短语平静呈现，不逐字飞入、不跑马、不做卡拉OK变色；拼音和对应汉字同时出现与消失。不要只将整句拼音放在整句汉字上方，那不能保证逐字对齐。

## 时间轴

以真实配音对齐短语边界，沿用25fps帧格。常规显示1.5–4秒为排版目标，实际语句短于1.5秒时不为凑时长覆盖下一句；长句在自然短语处拆开，不按字数平均分配整片。

优先使用可靠音频对齐/可用边界数据；已有音轨可依据句内真实静音区间，在自然标点处拆分较短字幕，并记录对齐方法，再听看复核。原稿句级时间只能作为外层边界，拆成多个短语需要重新定位。字幕不重叠、起止合法、不越过成片；可轻微跨入句后留白便于阅读，但不侵入下句。以当集口播末句结束时间清空字幕，保留约8秒安静尾声。

## 可编辑实现与交付

- `subtitles.ruby.json`：UTF-8、NFC，保存cue ID、对应剧本镜/句、文本、开始/结束秒数及`tokens`数组；每个token记录汉字、拼音、校对状态/覆盖原因，标点拼音为空。
- `episode.ass`：按字格测量后，用绝对定位的汉字与拼音事件共享同一起止时间；底板为独立绘图事件。ASS没有可依赖的原生ruby标签，不能只写HTML `<ruby>`后宣称播放器会支持。
- `episode.srt`：纯汉字兼容副本；SRT不保证字体或逐字上下对齐，不作为拼音字幕验收依据。
- `epNNN.mp4`：将ASS或等效透明字幕层合成到无字幕母版上，保留原音轨与总时长。`epNNN_clean.mp4`保留无字幕母版；平台上传烧录版时避免再次开启自动字幕形成重影。
- 保存字幕布局源、字体版本/哈希及许可、人工校对表。具体渲染/注音程序尚未随04工程导入；本规范和[版式示意](templates/subtitle-layout.svg)不是运行中的生产管线。

示例数据（实际生产须填实测时间，以下仅示意“晚安。”字级映射）：

```json
{"text":"晚安。","tokens":[{"hanzi":"晚","pinyin":"wǎn"},{"hanzi":"安","pinyin":"ān"},{"hanzi":"。","pinyin":""}]}
```

## 必检

汉字覆盖率100%；所有非标点token都有符合约定的拼音；token合并与原稿一致；多音字、轻声、变调、儿化已人工核对；调号无缺字或裁切；拼音居中且互不相撞；超长音节、9字短语、两组字幕均试排。至少抽查开头、中间、结尾，并完整听看烧录发布版，在360px宽预览核对可读性、平台遮挡和关键画面遮挡。未听看时明确写“待审”，不以覆盖率替代发音校对。

## 004本地光栅化校准（2026-11-11）

用户目标仍为汉字76px、拼音48px。当前本地Noto Sans CJK SC Regular与Noto Sans Regular经libass度量，需要ASS实现字号114/66才与Pillow 76/48参考尺度匹配；实际样片可见墨迹高度72/48px。数值差来自渲染器字体度量，不能直接把ASS字号改回76/48导致成片小字。证据在`episodes/ep004/v001/checks/font-calibration.json`及最终手机抽帧；将来换字体/渲染器需重测，不覆盖旧001。
