# 声音规范

版本：1.4｜更新：2026-11-11（北京时间）。依据：第001集第二版及 `03_素材与参数/配音与声音参数.json`。除用户明确确认变更外，后续新集沿用本规范。

## 当前声音参数（语速参数已确认）

| 参数 | 当前值 |
| --- | --- |
| 服务 | Microsoft Edge在线语音，通过edge-tts |
| 音色 | `zh-CN-XiaoxiaoNeural` |
| rate | `-35%` |
| pitch | `-2Hz` |
| volume | `+0%` |
| 后期 | `highpass=f=65,equalizer=f=3200:t=q:w=0.8:g=-2`，仅对完整旁白应用一次 |
| 工作格式 | 48kHz、单声道、16bit PCM WAV |

试听参考是听感基准，不是声音克隆模型。不得用其他声线叠滤镜冒充该音色；edge-tts参数也没有额外的“温柔模式”或强制耳语模式。

## 语速与时长

`rate=-35%` 是edge-tts请求参数，不等于成片整体时长按比例缩短，也不能直接换算成其他TTS模型的速度值。2026-11-11用户再次明确：保持系统当前声音参数，把采用稿完整播完，超过五分钟也可以。不设五分钟或其他固定片长上限，不为片长删文、补空白、加速或整体拉伸音轨。v5正文来自 `narration_paragraphs[].text`，不增加年龄说明。最终镜头、停顿和字幕必须以实际合成音频为准。

多场景版v3的约120秒及270–295汉字属于历史版本排产依据，不适用于用户长稿v5。历史001–003实测约2.90汉字/秒仅可粗估，不能冒充新稿音频的实测时长。

## 分句、留白与尾声

- 首集基准：开场画面和音乐先建立1.0秒；常规句间停顿0.72秒；段落停顿0.95秒；收尾句间约1.1秒；末句后约8秒尾声。
- 已有分句稿优先使用JSON内的 `pause_after_s`。v5只有完整口播段落，制作时按原文细分语句、记录自然停顿和实际测量，不把段落强行当成单张图片或单条字幕。音频天然停顿已存在时，不要重复补出过长空白。
- 按句保存源MP3与文本、参数及缓存摘要。缓存键至少包括文本、音色、rate、pitch；任一变化都应使对应句子缓存失效。
- TTS结果必须有真实可解码音频；空文件或失败响应不能算成功。

## 片段整理与响度

每条源音频解码至48kHz单声道float32。确认非静音后，按阈值 `max(0.0025, peak×0.008)` 找有声范围，头部保留0.11秒、尾部保留0.16秒。不可切掉字头或所有气口。

响度整理使用峰值3%阈值计算active RMS，目标0.105，增益同时受片段峰值0.72限制；保存前确认绝对样本值小于1。0.105是活跃样本RMS目标，不是LUFS或播放音量。

保留源MP3、处理后纯配音WAV和最终混音WAV。处理前WAV可由源MP3重建，无需重复分发。

## 混音

先确认人声清楚且句尾完整，再加入柔和程序音乐与极轻环境底噪。音乐和环境声前2秒淡入、末5秒淡出。检查峰值和削波，并试听中段与结尾；不得淡出后再无条件抬高全片增益。参数是文件波形参考，不承诺不同设备上的声压或助眠效果。

## 制作时的听感与字幕协作

- 继续使用已验收参数，不因参考cure而改用`speed=0.84`或其他模型。原第二版参考WAV未导入；[v004配音](../../episodes/ep001/v004/audio/voice.wav)是用户此前确认的-25%历史样本。用户随后明确将当前语速改为-35%；新[v005配音](../../episodes/ep001/v005/audio/voice.wav)采用新参数，依据见[语速决定](../../episodes/ep001/v005/audio/RATE_DECISION.json)，音频听感与成片反馈另记。
- 温柔自然地连贯讲述，保留句尾和气口，不逐字拖长、不加夸张角色声或耳语滤镜。先试听包含开场、长句、多音字与当集结尾的代表性片段，再合成全篇。
- 拼音只用于画面阅读，不增加拼音口播，不为读字幕而整体降速。字幕按[逐字拼音规范](SUBTITLE_SPEC.md)在自然短语处拆分；错读修音频，再同步拼音与时间轴。
- 首集文档中的约3.2中文字/秒仅用于排产估计，不是新的合成设置或验收硬阈值。实际记录纯口播时长、停顿与全片时长，不能把三者混成一个语速值。

## 当前可用工具配置

采用`edge-tts==7.3.1`。云环境中显式使用继承的HTTPS代理，并向TLS上下文加载平台CA（SSL_CERT_FILE），保持证书验证开启。旧7.2.7曾返回403，不能沿用旧客户端错误地判断云环境不支持WebSocket。001已按此配置生成并获用户确认；新增台词使用同一声线与参数，不重复询问已确定的音色和语速。
