## 当前标准

后续新制作和重制统一使用v5 JSON。每集p000必须纳入完整配音、字幕、时间轴，并与正文分开规划一镜或多镜，为每个片头镜头生成独立插画。一般每幅图约8–10秒，尽量不超过15秒；4–5分钟可按约24–38幅剧情图估算排期，实际数量依口播、语义和人物动作调整。封面另算。

声音为晓晓`-35%/-2Hz/+0%`、48kHz；完整口播，不限五分钟、不删文、不拉伸。画面使用静态水彩插画、25fps、0.96秒镜间叠化；发布字幕逐字对应带调拼音，汉字76px、拼音48px。封面只放主题短标题。每集交付发布版、无字幕母版、封面、三平台标题与含标签正文，以及可编辑工程和来源证据。
