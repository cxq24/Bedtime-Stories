# 统一封面规范

版本：bedtime-cover-v2｜2026-11-12更新。固定版式沿用已认可的004；用户要求标题优先统一四字，确实无法说清时用五字或六字，易懂且有吸引力。

## 固定与可变

每集独立交付1张1080×1920、9:16、sRGB PNG。固定颜色、字体、位置、圆角卡片；只替换本集背景和短标题。封面不计入剧情图数量，不默认作为片头插入，不延长开场音乐。用户长稿的剧情图数量可变，不能因沿用旧模板退回固定九图。

- 底图：本集独立插画或本集一张合适原图，保持水彩和细纸纹，按本集地点、时间与天气选色。选图展示当集事件、角色或关键道具，造型遵循对应版本角色JSON。
- 生成底图无文字，标题后期排版，不让图像模型生成汉字。
- 标题默认四个汉字，四字不能准确表达时用五字或六字；最多两行、每行最多4字，按词义换行。用具体人物互动、物件或小事件引起兴趣，让小朋友和家长容易理解；不用生僻缩写、抽象说教、夸张承诺或制作标签。不要为了凑四字牺牲清楚和自然。
- 004现有标题“半坡歇歇”获准保留，不重新出封面。用户语音转写中的“core.png”对应交付文件`cover.png`。
- 当前v5的短标题由各集JSON的 `cover_title` 提供。初版001历史成片对应“晚安星光”。

## 1080×1920版式

| 元素 | 固定参数 |
| --- | --- |
| 背景 | 全幅铺满，等比裁切；主体与故事物件主要落在x120–900、y180–1080 |
| 色板 | 深夜蓝`#182232`、暖米白`#FFF4DC`、柔金`#D9B77B` |
| 标题卡 | x108/y1140/w864/h440，圆角48，暖米白94%不透明；不遮角色脸或关键道具 |
| 文字范围 | 框内只显示本集主题短标题；不显示账号名、系列名、副标题或其他文字 |
| 主标题 | 中心x540，首行文字顶部y1260，第二行y1392，112px、Bold，行高132px，深夜蓝；单行时在卡片内垂直居中（中心y1360） |
| 字体 | Noto Sans CJK SC；禁止花体、细线字、描边挤满笔画；同批固定字体文件与版本 |
| 安全区 | 文字都在x108–972/y180–1600；中心3:4裁切（y240–1680）仍保留标题。具体平台另测，不承诺所有平台裁切一致 |

模板：[cover-template.svg](templates/cover-template.svg)。SVG中的灰蓝布局底与提示只供排版，不是已完成剧情插画；替换`episode-art`图层、编辑标题、隐藏`guides`再导出PNG。超过6字应精炼文案，不缩小字号强塞。单行/两行采用同一模板，不逐集重做视觉设计。

## 交付与检查

保存`cover.png`、可编辑`cover.svg`、无字底图、标题文本、源图路径/提示词、字体许可与模板版本。封面应在1080px和缩至360px宽时检查：标题易读、字形完整、内容与本集一致、关键物件不被遮挡、安全裁切无缺字。封面本身不要求拼音；逐字拼音是正片字幕要求。
