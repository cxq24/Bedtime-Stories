## 标准规范

晓晓rate=-35%/pitch=-2Hz/volume=+0%，48kHz；完整口播不删文、不限五分钟。v5每集p000片头需独立规划并配图。画面为静态水彩图、25fps、镜间0.96秒叠化；字幕逐字对应拼音，汉字76px、拼音48px；每集交独立封面及抖音、小红书、微信视频号三套标题和含标签正文。详见[专项规范](docs/production/)。
