## 唯一剧本源与片头

1. 只读目标集的`02_100集剧本/用户长稿v5/结构化JSON/epNNN.json`，以`narration_paragraphs[].text`为完整口播。不要从历史MP4、旧单集工程快照或导出的Markdown拼新稿。
2. 001–100集都有专属`p000`开场。开场须进入配音、字幕和时间轴，须与正文分开规划一镜或多镜，并为每个片头镜头生成独立插画；不得复用封面或剧情图。
3. Markdown合集、片头清单和单集Markdown是从v5 JSON导出的阅读视图，不是另一个稿源。修改JSON后运行：

   ```sh
   python3 local/export_opening_scripts.py --validate-only
   ```

旧v2/v3/v4替代剧本已从当前工作树移除；Git历史仍可追溯。角色图库文件名中的“v4”指图库版本，不是剧本版本。

## 剧情图数量与镜头节奏

**镜头和剧情图数量按本集完整口播、实际配音、语义转折和人物动作来定，没有固定九镜或固定九张图的要求。**

- 通常每幅图对应约8–10秒，动作短、人物状态变化或场景转换时可更短；按分镜规范检查单幅图的可见时长，尽量不超过15秒。
- 4–5分钟成片可先按约24–38幅剧情图排期；这是估算区间，不是硬性上限。节奏需要时镜头可更多或更少，最终按分镜与配音校准。
- v5的p000片头要有自己的镜头和独立插画，计入剧情图数量。封面另算，不充当剧情图。
- 镜头内画面固定静止；25fps，镜头间0.96秒叠化。不得为了凑固定张数把剧情合并，也不得机械按秒切图。

## 固定制作标准

| 项目 | 要求 |
| --- | --- |
| 剧本 | v5完整口播；不设五分钟上限，不删正文、不为缩短成片拉伸录音 |
| 配音 | 晓晓`zh-CN-XiaoxiaoNeural`，rate `-35%`、pitch `-2Hz`、volume `+0%`、48kHz；以实际合成音频锁定时间线 |
| 插画与表演 | 水彩、逐镜对应剧情；入镜角色实际加载图库参考；身份外形固定，表情、视线和姿态随当前情节变化；同一连续场景保持布局与服装连贯 |
| 字幕 | 每个汉字上方放对应带调拼音；汉字76px、拼音48px；按自然语音停顿拆短语，逐句校音 |
| 封面 | 独立1080×1920 PNG；框内只放当集主题短标题，四字优先，必要时五或六字 |
| 平台文案 | 抖音、小红书、微信视频号分别交标题和正文；每份正文含相关标签 |
| 输出 | 发布版MP4、无字幕母版、封面、三平台文案；可编辑工程、音轨、字幕、分镜、提示词、来源和检查报告 |

## 新集制作流程

1. 确认用户指定集数；查`PROJECT_STATE.json`和状态台账，核对是否已有工程、当前版本和未完成任务。
2. 从v5 JSON保存脚本快照和完整口播单元；将p000独立纳入配音与分镜。
3. 先规划覆盖完整口播的分镜；合成真实配音后，按词边界校准镜头时长、字幕和音床。
4. 每镜生成对应插画并核对角色身份、场景、动作和当下表情；不得把角色参考图里的默认神情复制到所有镜头。单独生成片头图。完成逐字拼音检查、封面和三平台文案。
5. 渲染发布版与无字幕母版，执行技术检查和完整解码；技术检查、人工听看、用户验收分别记录。
6. 工程放`episodes/epNNN/vNNN/`，最终交付放`Outputs/YYYY-MM-DD/epNNN-vNNN/`；更新主控、台账、机器状态和单集`RECORD.md`。

## 云端环境与发布

在云端仓库根目录按[云端接手说明](../云端接手.md)运行`bash local/setup_cloud.sh`，再运行`.venv/bin/python local/cloud_preflight.py`。预检不合成配音、不生成图片、不渲染视频；Edge TTS网络和可加载参考图的图像生成能力需在目标环境另行确认。

制作、技术检查、人工听看、用户验收、GitHub同步和平台发布是不同状态。视频默认不上传GitHub；第006、007、008、009集各自v002是已授权的同步例外。没有明确发布授权时，不向社交平台发布。
